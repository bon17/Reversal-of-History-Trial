## 3. 「문장을 하나씩 깨는 증언」 데이터 모양

`증언: { 제목, 증인, 표정, 문장: [...], 반대심문전: [...], 깨기: [...], 일반오답: '일반', 피해오답: '피해' }`

- `깨기`의 한 칸 = 깨야 할 것 하나. 칸끼리는 **어떤 순서로 깨도 된다**. 모두 깨면 증언이 끝난다.
- 칸 안의 값
  - `문장`: 깰 문장 번호. `1`, `'3-1'`, 또는 `[3, 4]`(둘 중 아무 데나)
  - `증거`: 정답 증거 id (배열이면 그중 아무거나)
  - `정답장면`, `힌트`
  - `힌트숨김`: 깰 문장이 아직 숨어 있을 때의 힌트 (증언 1의 "추가 전")
  - `증언없이: true`: 반대 심문 없이 증거만 고른다. 주장으로는 `앞`의 마지막 대사, 없으면 바로 앞에 나온 대사를 띄운다
  - `앞`: `증언없이` 단계 직전에 나오는 장면
  - `마지막: true`: 다른 칸을 모두 깬 뒤에야 차례가 온다
  - `이어서`: 이 칸을 깨면 이어지는 다음 단계 (같은 모양, 겹쳐 쓸 수 있음)
- 아직 차례가 아닌 정답(같은 문장의 다음 단계 증거 등)을 내면 벌칙 없이 그 차례의 힌트가 나온다.
- 틀리면 그 문장에서 깰 것의 힌트, 없으면 남은 것 가운데 첫 번째의 힌트가 나온다.
- 깬 단계 뒤 반대 심문으로 돌아오면 반대 심문 음악으로 돌아간다.

### 6화 증언 네 개를 이렇게 쓴다

| 증언 | 쓰는 방식 |
|---|---|
| 증언 1 「명령서」 (아이히만) | 문장 다섯 개: 1, 2, 3, `{ 번호: '3-1', 숨김: true }`, 4. 3번 `추궁`에 대본 `[3번 추궁]` 장면을 넣고 그 안에 `{ 증언수정음 }` → `{ 증언추가: '3-1' }`. `깨기: [{ 문장: '3-1', 증거: 'hanna_notebook', 힌트: (추가 뒤), 힌트숨김: (추가 전) }]`. 3-1의 `추궁`은 대본에 없으니 아이히만의 "…1941년 여름, 하이드리히가…" 대사를 다시 쓴다 |
| 증언 2 「기록 속의 목소리」 (히틀러) | `깨기` 네 칸 (1 나치 경제, 2 수권법, 3 T4 → `이어서: { 증언없이: true, 증거: 'speech_1939' }`, 4 네로 명령). 정답 장면마다 `{ 붉은줄: N }`. 힌트는 대본의 (1번)~(4번) |
| 증언 3 「거부할 수 없었다」 (크라우제) | 예전 방식(`정답: [{ 문장: 3, 증거: 'battalion101' }, { 문장: 4, … }]`)으로 충분. 외침은 `'이의 있음 초록'`. 정답 장면 끝의 실제 역사 기록은 `{ 기록카드 }` |
| 증언 4 「톱니바퀴」 (아이히만) | 문장 1, 2, 3, `{ 번호: '3-1', 숨김: true }`, 4. `깨기`: 2 반제 / 3 헝가리 수송(정답 장면 끝에 `{ 붉은줄: 3, 절반: true }`, `{ 증언추가: '3-1' }`) → `이어서: { 문장: '3-1', 증거: 'wisliceny' }` / 4는 `{ 문장: 4, 증언없이: true, 마지막: true, 앞: [증언 듣기: 다비드 (1961년) 장면 전체 + 「4번을 깰 때」의 아이히만 대사], 증거: ['battalion101', 'treatment_record', 'fuse', 'righteous'] }`. 대본에서 「증언 듣기: 다비드 (1961년)」은 ## 구간이지만 증언 4 한가운데에 있어서 `앞` 안에 `{ 구간: '증언 듣기: 다비드 (1961년)' }`을 넣는다 |

### 막과 연출 (대본의 [연출] → 게임)
1. **명령서는 없다**: 프롤로그(기록실, 한나가 기록을 펼치면 `보이기 한나 걱정`, 하야시는 `등장` + 이름표 `['하야시', null, '3화에서 무죄를 받은 기자']`) → 오프닝(예루살렘 법정 배경, 효과음 세 개, (목소리, 통역), 암전 자막) → 역사 배경(🟥 생존자 증언은 `차분하게`)
2. **피고 면회**: 면회실에 한나(`보이기 한나 피고석 포즈`), 증거 두 개, 선택지
3. **조사**: 장소 넷, 조사 포인트 없음(도착 대화만). 1~3은 처음부터 열고, 4(기록 보관함)는 1~3을 다 본 뒤 연다("법정으로 가요"로 끝나서). 4에서 `꺼내기` → 안내창 → 101 대대, 교과서, (`연출: 반짝`) 어빙 판결
4. **개정**: 신문 기사 `증거보이기`, 레테의 두 줄 목록, 검찰 측 증거 `증거보이기`, 선택지(오답: 한나 슬픔) → `{ 부제목: ['**1라운드: 명령한 자는 잘못했는가?**'] }` → `카메라 방탄유리 부스` + `등장 아이히만` + 이름표 → 증언 1. 정답 장면 끝 "법정의 조명이 어두워진다"는 배경만 어둡게(기록 버튼은 남게) 하는 연출이 필요하다 (`연출: '어둡게'`는 법정 기록 버튼을 숨기므로 쓰지 말 것. screen.js에 dim 켜고 끄는 함수를 더해 `조명 어둡게`/`조명 밝게`로)
5. **기록 속의 목소리**: BGM 없음 + `{ 효과음: '낮게 울리는 소리', 반복: true }` + 필름 소리 → `등장 히틀러 무표정` + 이름표 → 증언 2 시작 전에 반복 소리 멈춤 → 증언 2 → 레테의 반격 「명령서는 없다」(정답 어빙) → 1라운드 결론(`판결 유죄`, `보이기 히틀러` 뒤 `퇴장 히틀러`, 기록카드 2줄, `조명 밝게`)
6. **그게 끝이 아니었다**: 의자 소리 + `보이기 한나 결의` → 몽타주(오카다 무너짐, 사토 당황, 야마모토 무너짐, 다나카 무너짐, 슈나이더 무너짐, 베커 무너짐. 대본 줄 그대로) → `부제목 2라운드` → 크라우제 `등장` + 이름표 `['크라우제', 'Krause', '전직 경찰']` → 증언 3 → 레테의 반격 「더 높은 곳의 사람」(증거 제시 없음, 끝에 `카메라 방탄유리 부스` + `등장 아이히만`)
7. **톱니바퀴**: 증언 4 (위 3장. 증언 듣기에서는 `{ 배경: '방청석 (어둡게)', 화면밖: ['재판장'] }`, `연출 어둡게`, `보이기 다비드 슬픔`, 끝나면 `연출 밝게`, `배경 기억의 법정`. 안경 닦는 컷 `backgrounds/cut_ep6_eichmann_glasses`) → 2라운드 결론(`배경 1961년 예루살렘의 법정` + `종이` 4줄, 법정으로 돌아와 `판결 '1961년 예루살렘 판결은 옳았다'`, `카메라 방탄유리 부스 + 책상 booth_off`) → 레테의 반격 「평범한 독일인」(정답 교과서)
8. **최종 변론**: 악의 평범성(개념 카드, 몽타주 `1화: 감독관 오카다, 광업소장 사토` … `6화: 예비경찰 크라우제, 그리고 아돌프 아이히만`, 얼굴은 기본·온화함 같은 평소 얼굴, 아렌트 문장 자막) → 최종 변론(대사마다 대본에 적힌 카드 `증거보이기`) → 판결 무죄 → 실제 역사 기록
9. **두 개의 결말**: 복도(레테는 `퇴장 뒷모습` → 대사 → `퇴장`) → 기억의 벽(`벽돌`) → 두 나라의 결말(배경 '기억의 법정 기록실 (벽에 커다란 세계 지도)', `표`, 질문 자막) → 마지막 장면(기억의 법정 입구 → 계단 올라가며 '역사관 지하 계단' → 엔딩 자막 세 장) → 「반박문 쓰기」 구간: BGM, 자막 한 줄, `{ 반박문: true }`
