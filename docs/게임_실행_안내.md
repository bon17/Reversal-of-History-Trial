# 「기억의 법정」 게임 실행 안내 (선생님용)

게임 1(제1화 「군함도의 명부」, 제2화 「두 개의 국적」, 제3화 「첫 번째 보도」)과 게임 2의 제4화 「숨겨진 방」, 제5화 「아버지의 시계」를 웹 브라우저에서 바로 플레이할 수 있다. 3화 끝에는 기억 노트(쓰기 활동)가 이어진다. 설치할 것은 없다.

---

## 1. 실행하기

### 방법 1: 웹 주소로 열기 (크롬북, 태블릿, 휴대폰에 추천)
클라우드플레어에 올린다. 설정은 기획서 13장에 있다.
1. 클라우드플레어 대시보드에서 새 프로젝트를 만들고 이 GitHub 저장소를 연결한다. (비공개 저장소도 된다)
2. 빌드 명령은 `mkdir -p site && cp -r index.html manifest.webmanifest game assets site/`, 빌드 출력 디렉터리는 `site`로 정한다.
3. 나오는 주소를 학생들에게 나눠 준다.

- 게임에 필요한 파일만 올리는 것이 중요하다. 저장소 전체를 올리면(GitHub Pages로 루트를 올리는 경우 포함) `docs/`의 대본, 곧 모든 정답과 교사용 메모가 주소만 바꿔 열린다.

### 방법 2: HTML 파일 하나로 열기 (가장 간단)
- 게임 1과 게임 2를 **파일 두 개**로 나누어 담는다. 한 파일에 다 넣으면 30MB를 넘어서 보낼 수 없기 때문이다.

| 파일 | 담긴 것 | 크기 |
|---|---|---|
| `기억의_법정_게임1.html` | 1~3화, 기억 노트. [처음부터]가 1화 | 약 29.5MB |
| `기억의_법정_게임2.html` | 4화부터 (6화를 만들면 함께 들어감). [처음부터]가 4화의 게임 2 시작 화면 | 약 27MB (5화까지) |

  - 처음 화면의 로고 아래에 "게임 1 · …" / "게임 2 · …"가 보여서 어느 파일인지 알 수 있다.
  - 이어하기 코드는 그 파일에 든 화의 코드만 받는다. 게임 2 파일에는 [기억 노트 쓰기]가 없다.
  - 그 게임에서 쓰는 그림만 넣는다. 게임 2의 지난 기록처럼 1부 인물 얼굴이 필요한 곳은 그 그림만 함께 넣는다.
  - 6화를 넣어 게임 2 파일이 30MB를 넘으면, 그 파일만 인물 그림을 조금 작게 넣거나 4화와 5·6화로 한 번 더 나눈다. (5화까지 약 27MB)
  - 기억 노트 답을 구글 시트에 저장하려면 인터넷이 필요하다 (아래 11장).
- 이 파일을 USB나 구글 드라이브로 옮겨서 더블클릭하면 크롬에서 바로 실행된다. 인터넷이 없어도 된다.
- 만들기: `node tools/build_single_html.mjs` → `dist/기억의_법정_게임1.html`, `dist/기억의_법정_게임2.html` (하나만: `--game 1` 또는 `--game 2`)
- 소리 파일은 들어가지 않는다. 리디바탕 글꼴은 `game/fonts/`에 글꼴 파일이 있으면 함께 들어가고, 없으면 인터넷이 될 때만 나온다.

### 방법 3: 폴더로 열기 (학교 컴퓨터)
- 저장소 전체를 내려받아 압축을 풀고 `index.html`을 더블클릭한다. 인터넷이 없어도 된다.

### 지원하는 브라우저
- 크롬, 엣지, 웨일의 최근 버전
- 아이패드·아이폰 사파리 15 이상 (iOS 15 이상)
- 삼성 인터넷

## 2. 조작 (학생 안내용)

| 할 일 | 방법 |
|---|---|
| 대사 넘기기 | 화면을 누르기 (Enter·스페이스로는 넘어가지 않는다. 잘못 눌러 대사를 놓치지 않게) |
| 글자 한 번에 보기 | 글자가 나오는 동안 한 번 누르기 |
| 반대 심문 문장 넘기기 | ◀ ▶ 버튼, 또는 키보드 ← → |
| 추궁 / 증거 제시 | [추궁], [증거 제시] 버튼 |
| 모은 증거 보기 | 오른쪽 위 [법정 기록] → 아래 작은 칸을 누르면 위 큰 칸에 그림과 설명이 나온다 (키보드 ← →). 8개가 넘으면 ◀ ▶로 쪽 넘기기 |
| 증거 제시 | [증거 제시] → 작은 칸에서 증거를 고르고 → [증거 제시] |
| 글자 속도, 소리 크기, 지난 대사 | 오른쪽 위 ⚙ |
| 전체 화면 | 오른쪽 위 ⛶ |

아이폰은 브라우저가 전체 화면을 지원하지 않아서 ⛶ 버튼이 보이지 않는다. 대신 사파리의 공유 버튼 → **홈 화면에 추가**로 저장한 뒤 그 아이콘으로 열면 주소창 없이 전체 화면으로 실행된다.

### 화면 배치
- **가로 화면** (컴퓨터, 크롬북, 태블릿 가로, 휴대폰 가로): 3:2 장면 위에 대사창과 버튼이 겹친다.
- **세로 화면** (휴대폰 세로, 태블릿 세로): 위에는 장면, 아래에는 대사창과 버튼이 놓인다.
- 기기를 돌리면 진행은 그대로 두고 배치만 바뀐다.

## 3. 이어하기와 이어하기 코드

- 게임은 장면(구간)이 바뀔 때마다 그 브라우저에 자동으로 저장된다. 처음 화면의 **[이어하기]**를 누르면 마지막 장면부터 다시 시작한다.
  - 저장은 그 기기(브라우저)에만 남는다. 다른 컴퓨터로 옮기면 그 화를 처음부터 해야 한다.
  - HTML 한 파일로 할 때는 게임 1 파일과 게임 2 파일이 저장을 따로 한다. 한 컴퓨터에서 두 파일을 오가도 서로의 진행을 지우지 않는다.
    - 파일을 나누기 전에 저장한 진행은 처음 화면을 열 때 그 화가 든 파일 쪽으로 옮겨진다.
- **이어하기 코드**는 한 화에 하나이고, **그 화의 제목**이다. 처음 화면의 **[이어하기 코드 입력]**에 넣으면 그 화의 처음부터 시작한다.
  - 띄어쓰기, 따옴표, 낫표(「」)는 무시한다. `두 개의 국적`, `두개의국적`, `「두 개의 국적」` 모두 된다.
  - 1화는 [처음부터]로 시작하므로 코드가 없다.
  - 한 화를 끝내면 "다음 화 예고"에 다음 화 제목이 나온다. 다음 시간에 학생들이 그 제목을 넣으면 바로 이어서 할 수 있다.
  - 다음 화가 이미 만들어져 있으면, "다음 화 예고" 화면에 **[제N화 시작]** 버튼이 나와서 바로 이어 할 수도 있다.

| 화 | 이어하기 코드 |
|---|---|
| 1화 「군함도의 명부」 | 없음 ([처음부터]) |
| 2화 「두 개의 국적」 | `두 개의 국적` |
| 3화 「첫 번째 보도」 | `첫 번째 보도` |
| 4화 「숨겨진 방」 (게임 2 시작) | `숨겨진 방` |
| 5화 「아버지의 시계」 | `아버지의 시계` |

- 게임은 두 개로 나누어 수업한다 (기획서 2-6). 게임 1은 [처음부터], 게임 2는 4화 코드 `숨겨진 방`으로 시작한다. (게임 2 파일은 [처음부터]가 곧 4화)

- 코드는 각 화 데이터 파일(`game/data/ep2.js` 등)의 `코드:` 자리에 적혀 있다.
- 🟩 선택 기록은 6화의 기록 보관함에서 다시 쓰기 때문에, 얻을 때마다 그 브라우저에 화별로 따로 모아 둔다.

## 6. 그림 바꾸기와 WebP 복사본

- 원본 그림(`assets/`)은 게임이 읽기만 한다. 게임은 용량을 줄인 복사본 `game/img/…webp`를 먼저 쓰고, 복사본이 없으면 원본 PNG를 쓴다.
  - 그림 전체 크기 (1~3화 그림): 원본 약 266MB → 복사본 약 21MB
- **새 그림을 추가**하면 복사본이 없어도 바로 게임에 보인다. 다만 원본이라 무겁다.
- **있던 그림을 바꾸면** (예: 다시 그린 `ep1_quota_table`) 옛 복사본이 계속 보이므로, 복사본을 다시 만들어야 한다.
- **인물 그림이 흰 배경 그대로 올라오면** (네 귀퉁이가 흰색), 복사본을 만들 때 흰 배경을 지운다. 원본은 그대로 둔다. 가장자리와 이어진 흰 부분과 팔과 몸 사이에 갇힌 넓고 아주 흰 틈만 지우고, 흰 셔츠처럼 색이 조금 섞인 곳은 남긴다.
  - 투명한 원본을 올리면 다시 만들 때 그 원본을 그대로 쓴다. (5화 다비드 7장 등 10장이 처음에 흰 배경으로 올라왔다가, 그림 브랜치에 투명한 원본이 올라와 지금은 원본을 그대로 쓴다)

복사본 만들기 (Node.js와 Playwright가 있는 컴퓨터, 또는 Claude에게 "WebP 다시 만들어 줘"라고 요청):

```
node tools/make_webp.mjs          # 바뀐 그림만 다시 만든다
node tools/make_webp.mjs --all    # 전부 다시 만든다
```

| 종류 | 복사본 크기 |
|---|---|
| 배경, UI | 원본 크기 그대로 |

## 8. 대본에 지시가 없어서 정한 연출

대사는 바꾸지 않았다. 아래는 화면 배치와 순서만 정한 것이다.

- **신중한의 화면 등장**: 법정 밖에서는 역전재판처럼 화면에 서지 않는다. 대사창 옆 작은 얼굴로 표정을 보여 준다.
  - 면회실의 한나, 검은 화면의 모든 인물도 같은 방식으로 보여 준다.
- **법정 화면 전환**: 말하는 사람의 자리로 화면이 자동으로 바뀐다.
  - 신중한·한나: 변호인석 / 레테: 검사석 / 증인: 증언대 / 김석진: 피고석 / 재판장: 재판장석
- **추궁 문답의 표정**: 대본에 표정이 없어서, 신중한은 '진지', 증인은 그 증언에서의 표정으로 했다.
- **국가 총동원법**: 🟦 책임 기록으로 법정 기록에 넣었고, 제시할 수 있다. 강제 동원·사보타주는 '개념 카드' 칸에서 읽기만 한다.
- **오답 대사가 적히지 않은 곳**: 증언 3~6과 레테의 반격에는 증언 2의 일반 오답 대사(재판장, 레테)와 증언 1의 🟥 안내 대사(재판장, 한나)를 다시 쓴다.
- **"증거는 충분히 모인 것 같아. 법정으로 가자."**: 세 장소를 모두 조사한 뒤에 나온다.
- **박만수**: 갈림길 표지판을 조사한 뒤에 나온다.
- **증언 1**
  - 3번 문장은 추궁으로 수정된 뒤에만 구조 기록이 정답이다. 수정 전에 내면 🟥 안내가 나온다.
  - 수정된 3번을 다시 추궁하면 한나의 "갱도에서 나와 오른쪽에는…" 대사가 다시 나온다.
- **증언 3**: 썩은 버팀목을 먼저 내도 대본대로 점검 보고서 대사가 나온다.
- **"피고석의 김석진이 고개를 든다"**: 김석진을 '결의' 표정으로 보여 준다.
- **모리가 물러날 때**: 뒷모습 그림을 쓴다.
- **(목소리) 대사**: 검은 화면에 이름칸 "목소리"로 보여 준다.
- **실제 역사 기록 카드**: 누르면 닫히고, 이어지는 두 대사는 검은 화면에서 나온다.
- **장면 제목 띠**: 레테의 반격, 증언 듣기, 휴정, 최종 변론 장면 앞에 띄운다.
- **조사 파트 시작**: 조사 안내창과 장소 고르기 동안에는 면회실 배경만 남기고 김석진은 뺀다.
- **면회실**: 피고가 유리창 바로 뒤에 있다. 피고는 유리창 아랫단의 밝은 선(y≈752) 바로 위에서 잘려서, 아랫단에 틈 없이 닿으면서도 유리 안쪽에 있는 것처럼 보인다. 인물 위에는 옅은 유리 반사를 겹친다. 1~3화 면회실 모두 같다.
  - 예전의 "몸 아래쪽을 흐리게" 하던 방식은 귀신처럼 보여서 뺐다.
  - 아랫단보다 아래(창틀)까지 보이게 하면 유리 밖에 있는 것처럼 보여서 그렇게 하지 않는다.
- **증거 알림 글**: 보석 + 증거 이름 + 설명이 세 줄이 되어도 대사창 아래에 붙지 않도록, 증거 알림일 때만 글을 조금 위에서 시작하고 줄 간격을 줄였다.
- **대사 넘기기**: 글이 다 보인 뒤 0.4초 동안은 눌러도 넘어가지 않는다 (연타해서 읽기 전에 지나가지 않게). 글자가 나오는 중에 누르면 지금처럼 한 번에 다 보인다. Enter·스페이스로는 넘기지 않는다.
- **법정 기록 창**: 역전재판처럼 위에 큰 증거 칸(그림 + 이름 띠 + 줄 쳐진 설명), 아래에 작은 칸 8개를 둔다. 설명 칸 바탕과 작은 칸 테두리는 기록 색(🟥 빨강, 🟦 파랑, 🟩 초록, 개념 카드 금색)을 따른다. 가로 화면에서는 대사창을 가리지 않아 증언 문장을 보면서 고를 수 있다 (휴대폰 가로는 자리가 좁아 화면 전체를 쓴다). 실제 사진은 큰 칸 아래에 출처 띠를 함께 띄운다. 창을 다시 열면 마지막으로 본 증거가 골라져 있다.
- **"잠깐!" 외침**: 대본에는 증언 1의 3번 추궁에만 적혀 있지만, [추궁]을 누를 때마다 짧게 띄운다. 대사는 바꾸지 않았다.
- **법정 인물 크기**: 몸 아래쪽이 증언대·피고석 난간·책상 뒤에 숨도록 자리마다 크기를 줄였다.
- **시작과 끝**
  - 시작: 처음 화면 → 제1화 제목 → 프롤로그
  - 끝: 다음 화 예고 → 처음 화면

## 8-2. 2화에서 정한 것

## 8-3. 3화에서 정한 것

- **증언 1과 증언 4의 보조 정답**: 대본에 대사가 없던 두 장면은 선생님 확인을 받아 대본에 넣었다. 둘 다 반론 장면 뒤 반대 심문으로 돌아가고 신뢰도는 줄지 않는다.
  - 증언 1의 4번에 정정 기사를 내면: 기무라가 "처음부터 확인했다면 틀릴 일도 없었다"고 받고, 한나가 "확인하지 않았다"는 말부터 무너뜨리자고 한다. 정정 기사는 뒤의 레테의 반격에서 쓴다.
  - 증언 4의 4번에 김학순 할머니 기록을 내면: 다나카가 "명령서 이야기"로 돌리고, 재판장이 "결정적인 증거는 아니군요"라고 한다. 할머니의 증언을 의심하는 말은 넣지 않았다. 할머니의 대사는 실제 증언 한 문장만 인용한다.
- **재판장 놀람**: 대사는 그대로 두고, 결정적인 순간에 재판장이 놀라는 얼굴을 잠깐(약 1초) 보여 준다. 대본에는 「[연출] 재판장이 놀란다」로 적었다. 2화 네 곳, 3화 두 곳("다 태웠는데", "다나카, 당신입니다!"). 대본 확인 도구가 대본과 게임의 수를 비교한다.
- **오프닝**: 책상 위 신문 컷에 1면 제목을 겹쳐 띄우고, 전화 목소리 두 줄 뒤 기자 실루엣 컷으로 바뀐다. 이름칸에는 "전화 목소리"가 보인다.
- **🟥 피해 기록 연출(기록실)**: 화면이 어두워지고 차분해진 채 김학순 할머니의 공개 증언 기록을 얻는다. 실제 사진이라 알림에 출처 띠가 함께 나온다 (동아출판 『중학교 역사1』 199쪽).
- **증언 듣기**: 기자회견 사진(출처 띠)을 띄운 채 재판장이 말하고, 사진을 어둡게 비친 위에 기록 세 줄과 할머니의 실제 증언 한 문장을 차례로 띄운다.
- **위안소 분포도 제시**: 지도를 화면 가득 띄우고 표시점 187개를 북쪽부터 하나씩 켠다 (그림 대화에서 교과서 197쪽 지도를 옮겨 만든 점).
- **증언 4-2**: 1단계(소각 담당자 명단)는 반대 심문, 2단계(고발장, "받아라!")와 3단계(후세 다쓰지, 초록 "이의 있음!")는 증언 없이 증거만 고른다. 2단계에는 대본의 질문 "이름 말고 이 사람을 가리키는 단서는?"을 버튼 옆에 보여 준다. 명단을 낼 때 "다나○" 확대 그림을, 다나카가 무너질 때 지팡이가 떨어지는 컷을 띄운다.
- **실제 역사 기록**: 기록 카드 → 숫자 화면(155 → 240 → 46 → 5로 숫자가 바뀌고, 마지막에 5만 남으며 음악이 멈춤) → 두 번째 기록 카드 순서.
  - 생존자 수는 수업 직전에 최신 수치를 확인해서, 바뀌었으면 대본과 `game/data/ep3.js`의 숫자를 함께 고친다 (대본 교사용 메모).
- **1부 마무리**: 텅 빈 법정에서 모리, 야마모토, 다나카의 뒷모습이 차례로 안쪽으로 걸어가며 작아지고, 한 사람마다 한 줄씩 글이 남는다.
- **게임 1 엔딩**: 각색 안내 → 기억 노트 → [끝내기] → 게임 2 예고 → "수고했어요! 게임 1은 여기까지예요. / 다음 시간에 게임 2로 이어서 해요." → 처음 화면. (예고가 기억 노트 앞에 있으면 4화가 곧 시작될 것처럼 보여서 뒤로 옮겼다. 대본도 같이 고침)
- **기억 노트** (기획서 11장 그대로): 반·번호·이름 → 기억에 남는 증거 제시(법정 기록과 같은 창, 1~3화 증거) → 이유 고르기 → 진짜 잘못한 사람 → 그 사람의 잘못 한 줄 → 벌을 받았을까(고르면 바로 '미결' 안내) → "어쩔 수 없었다" → 이유 한 줄 → 저장.
  - 2화를 하지 않은 기기에서는 야마모토와 2화 증거가 나오지 않는다.
  - 반은 1~5반, 번호는 1~32번에서 고른다.
  - 1-2에서는 이유 버튼을 고르고, 기억에 남은 이유를 **한 문장으로 꼭** 쓴다 (시트의 "기억에 남은 이유(한 줄)" 열).
  - 마지막(4번)에 "왜 우리는 이 사건과 이들의 행동을 기억해야 할까요?"를 한 문장으로 쓴다 (시트의 "왜 기억해야 할까" 열). **이 열 때문에 `gas/Code.gs`를 새로 붙여 넣고 새 버전으로 다시 배포해야 한다.**
  - 저장한 뒤 [다시 쓰기]를 누르면 반·번호·이름은 그대로 두고 처음부터 다시 쓴다. 다시 저장하면 새 줄이 생기고, 요약에는 가장 최근 것이 쓰인다.
  - [끝내기]를 누르면 게임 2 예고와 "다음 시간에 게임 2로 이어서 해요" 안내가 나오고, 누르면 처음 화면으로 간다.

- **실제 사진 3장의 출처 띠** (선생님이 출처를 알려 줌): 아우슈비츠 정문과 신발 사진은 `encyclopedia.ushmm.org`, 가방 사진은 `jewishaction.com`. 띠에는 사이트 주소만 짧게 쓴다. 가방 사진의 전체 주소(https://jewishaction.com/holocaust/on-seeing-the-display-of-victims-suitcases-at-the-auschwitz-museum/)는 `ep5.js` 맨 위 설명에 적어 두었다.
  - 신발과 가방은 증거 하나에 사진 두 장이라 출처가 사진마다 다르다. 데이터의 `뒤집기.출처`에 사진 순서대로 적으면, 띠가 지금 보이는 사진의 출처로 바뀐다 (획득 알림과 법정 기록 칸은 카드 그림인 신발 사진의 출처).
- **다시 만든 그림 4장** (선생님이 그림 브랜치 `5e6719a`, `6b9a5f2`에 올림): 담요 속 금시계 컷(증거물처럼 뚜껑이 닫힌 금시계. 나중에 담요 모서리에 "베커 상회 기증" 도장이 보이는 `cut_ep5_watch_in_blanket_last`로 다시 바꿈, `f865b0a`), 번호 문신 확대(면회실 배경. 팔과 숫자 자리는 그대로라 번호 겹치기 좌표도 그대로), 시계 수집품(진열장 속 회중시계·손목시계·탁상시계 수십 개, 비매품 쪽지, 가운데 빈자리), 가방 더미 사진(이름과 주소가 보이는 실제 사진).
- **수색 기록의 "1946년 ○월 ○일"**: 선생님 결정으로 그대로 둔다.
- **인물 그림**: 처음 올라온 10장(다비드 7장, 베커·프리츠·야코프 기본)은 흰 배경이었으나, 그림 브랜치의 투명한 원본(`9ba000a`)으로 바꿨다. 흰 배경 그대로 올라오는 인물 그림은 WebP 복사본에서 배경을 지우는 처리도 넣어 두었다 (6장).
- **실제 역사 기록 카드** (1~5화 공통): 휴대폰 가로처럼 낮은 화면에서는 글을 조금 줄여 [계속]까지 한 화면에 보인다 (5화 카드는 문단이 6개라 넘쳤다).

## 10. 글꼴 파일 넣기

- 리디바탕 글꼴 파일을 `game/fonts/` 폴더에 올린다. 파일 이름은 아래 중 하나로 한다.
  - `RIDIBatang.woff2`, `RIDIBatang.woff`, `RIDIBatang.otf`, `RIDIBatang.ttf`
- 올리면 게임이 그 파일을 먼저 써서, 인터넷이 없어도 리디바탕으로 보인다.
- HTML 파일 하나로 만들 때도 이 글꼴이 함께 들어간다.

## 11. 기억 노트 저장 (GAS, 구글 시트)

게임 1이 끝난 뒤 쓰는 기억 노트의 답을 선생님의 구글 시트에 모은다. 스크립트 원본은 `gas/Code.gs`에 있다.

1. 학교 구글 계정으로 새 구글 시트를 만든다.
2. [확장 프로그램 → Apps Script]를 누르고, 나온 편집기의 내용을 모두 지운 뒤 `gas/Code.gs` 내용을 붙여 넣고 저장한다.
   - 편집기 위쪽 함수 목록에서 **`setup`**을 고르고 [실행]을 한 번 누른다 (처음이면 권한 허용). 시트에 「기억노트」, 「반박문」, 「요약」 탭이 생기면 잘 된 것이다.
   - `doPost`, `doGet`은 직접 실행하지 않는다. 게임이 부른다. 학생 답은 게임에 주소를 넣은 뒤부터 쌓인다.
3. [배포 → 새 배포 → 유형 선택: 웹 앱]을 고른다.
   - 실행 사용자: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자** (학생이 로그인하지 않아도 저장되게)
4. [배포]를 누르고 권한을 허용하면 웹 앱 주소(`https://script.google.com/…/exec`)가 나온다.
5. 이 주소를 `game/data/common.js`의 `DATA.설정.GAS주소: ''` 따옴표 안에 넣는다. (Claude에게 주소를 알려 주면 넣어 준다)
6. 스크립트를 고친 뒤에는 [배포 → 배포 관리 → 수정(연필) → 버전: 새 버전]으로 다시 배포한다. 주소는 바뀌지 않는다.

- 시트는 처음 저장할 때 저절로 생긴다: 「기억노트」(한 사람이 한 줄), 「반박문」(게임 2 뒤, 아직 게임에 없음), 「요약」(반마다 "어쩔 수 없었다" 세 답의 수, 이름 없음).
- 같은 학생이 여러 번 내면 모두 남고, 요약과 불러오기에는 가장 최근 것을 쓴다.
- 저장에 실패하면 [다시 보내기]가 나오고, 두 번 실패하면 쓴 답을 화면에 보여 준다.
- 칸마다 100자까지만 받는다. 장난으로 넣은 답은 시트에서 지우면 된다. 학기가 끝나면 시트를 지운다.
