# 기억의 법정: 역사 역전재판 기획서

> 중학교 2학년 역사 수업용 법정 추리 게임
> 교과서 연계: 역사① Ⅵ. 세계 대전과 사회 변동 (182~213쪽), 특히 **02. 전쟁 범죄에 맞선 평화 유지 노력 (194~203쪽)**
> 이 기획서는 1~6화 대본(`docs/대본/`)이 완성된 뒤 대본 내용에 맞춰 다시 정리한 것이다. 기획서와 대본이 다르면 **대본이 기준**이다.
> 게임은 **두 개로 나눈다.** 게임 1은 1~3화(제1부), 게임 2는 4~6화(제2부)이고, 게임마다 끝난 뒤 쓰기 활동이 있다. (2-6 참고)

---

## 0. 게임 소개 (5줄 요약)

1. 신참 변호사 신중한은 과거 사건의 기록이 다시 열리는 가상의 법정 **「기억의 법정」**에서 억울한 누명을 쓴 사람들을 변호한다.
2. 조수인 기자 한나와 함께 증거를 모으고, "그런 일은 없었다"고 우기는 망각의 검사 **레테**에 맞서 증언의 모순을 찾아 **"이의 있음!"**을 외친다.
3. **게임 1**(제1부, 1~3화)에서는 군함도, 포로감시원, 일본군 '위안부' 사건으로 **일제의 만행**을 파헤치고, **게임 2**(제2부, 4~6화)에서는 한 유대인 가족의 이야기로 **홀로코스트**를 따라간다. 두 게임 사이에는 자기 생각을 정리해 쓰는 시간이 있다.
4. 재판마다 진범은 증인석에 선 평범한 얼굴의 사람이었고, 그들은 모두 **"어쩔 수 없었다"**고 말했다. 마지막 재판에서 신중한은 히틀러와 아이히만을 무너뜨리며 **따른 사람에게도 책임이 있음**을 증명한다.
5. 모든 재판이 끝난 뒤 신중한은 깨닫는다. 기억하는 사람이 있는 한 진실은 사라지지 않고, **이제 여러분이 증인**이라는 것을.

## 1. 기획 배경과 목표

### 1-1. 학생 상황 (설계의 전제)
- 학생들은 도쿄 재판, 홀로코스트, 아이히만, 일본군 '위안부'를 **거의 모른다.**
- 인터넷 매체의 왜곡된 정보 때문에 **히틀러를 옹호하는 학생**도 있다. ("경제를 살렸다", "카리스마 있는 지도자였다" 등)
- 따라서 게임은 기초 사실을 알고 있다고 가정하지 않고, **게임 안에서 증거로 직접 보여 준다.**

### 1-2. 핵심 메시지 (세 계단)

| 단계 | 메시지 | 게임에서 쓰는 증거 |
|---|---|---|
| **1** | 이런 일이 있었고, 수많은 사람이 고통받았다 | 🟥 **피해 기록** |
| **2** | 히틀러와 일제는 명백히 잘못했다 | 🟦 **책임 기록** |
| **3** | "그땐 어쩔 수 없었다"며 따르고 지지한 사람들. 아렌트는 이것을 **악의 평범성**이라 불렀다. **그들도 잘못이 없는 게 아니다** | 🟩 **선택 기록** |

- 3단계는 반드시 2단계를 **판결로 확실히 끝낸 뒤에** 다룬다. 책임을 **나누는 것이 아니라 더하는 것**으로 보여 준다. ("히틀러만 나쁜 건 아니네 → 히틀러는 덜 나쁘다"라는 오해를 막기 위해서다.)
- 목표는 수업이 끝난 뒤 학생이 **히틀러와 일제를 옹호하는 말에 스스로 반박할 수 있게** 하는 것이다.

## 2. 게임 구조

### 2-1. 세계관: 기억의 법정
- 역사관 지하에 있는 가상의 법정이다. 묻혀 있던 과거 사건의 기록을 다시 열면 **기록 속 사람들이 법정에 나온다.**
- 이 설정 덕분에 주인공 한 명이 일본 사건과 독일 사건을 모두 맡을 수 있고, 히틀러 같은 역사 인물도 증인으로 세울 수 있다. 1961년 이후의 기록(1998년 독일 교과서, 2000년 어빙 판결 등)도 증거로 불러올 수 있다.
- 학생은 기억의 법정에서는 이긴다. 대신 사건이 끝날 때마다 **「실제 역사 기록」 카드**가 나와 현실은 어땠는지 보여 준다.

### 2-2. 역전재판 공식
1. **처음에는 피고가 정말 잘못한 것처럼 보인다.** 불리한 증거가 있다.
2. 변호를 하는 과정에서 **그게 아니었음이 드러난다.**
3. **진범은 법정에 증인으로 나온 사람**이다. 피고는 **완전히 결백**하다.
4. 진범은 처음부터 티 나지 않게 한다. 4화와 5화에는 **가짜 용의자**를 두어 의심이 옮겨 가게 한다.
5. 학생은 증언의 모순을 찾아 **"이의 있음!"** 과 함께 증거를 제시한다.

**교육적 의도:** 처음에 피고를 의심했던 학생이 진실을 알게 되면서 "겉으로 보이는 증거만 믿으면 안 된다"는 것을 몸으로 배운다. 역사 왜곡이 작동하는 방식이 바로 이것이다. 또 진범은 대부분 **친절하고 점잖은 사람**으로 등장해서, "악은 괴물의 얼굴을 하고 있지 않다"는 6화의 결론을 미리 겪게 한다.

### 2-3. 한 화의 진행 순서

| 순서 | 파트 | 내용 |
|---|---|---|
| ① | 프롤로그 | 기억의 법정 기록실. 이전 화에서 이어지는 장면 |
| ② | 오프닝 | 사건이 일어나는 짧은 실루엣 장면과 자막 |
| ③ | 역사 배경 | 한나가 교과서 수준으로 배경을 설명한다. 새 용어는 **개념 카드**로 바로 풀이한다 |
| ④ | 피고 면회 | 피고의 나이, 처지, 억울한 사정. **불리한 증거**를 알게 되고, 피고가 변호를 **의뢰**한다 |
| ⑤ | 조사 파트 | 장소를 조사하고 사람들과 대화하며 증거를 모은다 |
| ⑥ | 법정 파트: 개정 | 재판장이 사건을 다시 여는 이유를, 검사가 죄명과 흐름을 설명한 뒤 증인을 부른다 |
| ⑦ | 법정 파트: 증언과 반대 심문 | 증언을 한 줄씩 **추궁**하고, 모순되는 곳에 **증거를 제시**한다. 중간에 **레테의 반격**과 **휴정**이 있다 |
| ⑧ | 증언 듣기 | 피해자와 생존자의 증언을 선택지 없이 끝까지 듣는다 |
| ⑨ | 최종 변론 | 증거를 이어 진범을 지목하고 **"그러므로 피고는 무죄입니다!"** 라고 선언한다 |
| ⑩ | 판결 | 무죄 |
| ⑪ | 에필로그, 실제 역사 기록 | 실제 역사의 결말을 보여 주고 다음 화로 이어지는 단서를 남긴다 |

### 2-4. 법정 조작 규칙

| 상황 | 결과 |
|---|---|
| 추궁 | 벌칙 없음. 모든 증언 문장에 추궁 대사가 있다 |
| 〔강조 단어〕 | 증언마다 추궁해야 할 단어를 표시한다 (1화 튜토리얼에서 설명) |
| 일반 증거를 잘못 제시 | 재판부 신뢰도 1칸 감소 (5칸 중) |
| 🟥 피해 기록을 잘못 제시 | 벌칙 없음, 부드러운 안내 |
| 같은 증언에서 두 번 틀림 | 조수가 힌트를 준다 |
| 신뢰도 0 | "재판 연기" → 그 증언부터 다시 |

- **"아무 말도 하지 않는다" 같은 선택지는 두지 않는다.** 증거를 제시할 때까지 게임이 기다린다.
- 증거는 **[자세히 보기]** 로 확대할 수 있다. 확대해야 보이는 단서가 있다. (4화 S 서명, 5화 시계 뒷면 등)
- 조사나 증언으로 증거 내용이 바뀌는 **증거 갱신**이 있다. (2화 흉터 등)
- 외침은 **"이의 있음!"**(증거 제시), **"잠깐!"**(추궁), **"받아라!"**(연속 제시) 세 가지다.

### 2-5. 증거 카드 3종

| 색 | 종류 | 증명하는 것 | 예시 |
|---|---|---|---|
| 🟥 | **피해 기록** | 이런 일이 있었고, 사람들이 고통받았다 | 증언, 사진, 지도, 통계, 유품, 일기 |
| 🟦 | **책임 기록** | 누가 명령하고 실행했는가 | 명령서, 법령, 연설, 정책 문서, 서명 |
| 🟩 | **선택 기록** | 같은 상황에서도 다른 선택이 가능했다 | 명령을 거부한 사람, 독립운동가를 변호한 일본인, 유대인을 숨겨 준 사람 |

- 🟥 피해 기록을 제시하면 음악이 멈추고 화면이 차분해진다.
- 🟩 선택 기록은 초록빛 연출과 전용 획득음이 있다. 1~5화에서 모은 🟩 기록은 6화에서 **기록 보관함**에서 다시 꺼내 쓴다. 1부의 🟩 기록은 게임 2가 시작될 때 보관함에 자동으로 들어간다. (2-6 참고)

### 2-6. 두 개의 게임으로 나누기

여섯 화를 한 게임으로 이어 하기에는 분량이 많고, 1부와 2부는 묻는 것도 다르다. 그래서 게임을 둘로 나누고, 게임이 끝날 때마다 쓰기 활동을 둔다.

| | 게임 1 | 게임 2 |
|---|---|---|
| 부 | 제1부 「심판받지 않은 자들」 (일본) | 제2부 「평범한 사람들」 (독일) |
| 수록 화 | 1화, 2화 *(선택. 화 선택 화면에서 건너뛸 수 있음)*, 3화 | 4화, 5화, 6화 + 에필로그 |
| 시작 장면 | 타이틀 → 1화 프롤로그 (튜토리얼 포함) | **게임 2 시작 화면**: 지난 기록(1부 요약), 1부 기록 불러오기 → 「같은 전쟁, 다른 법정」 |
| 끝 장면 | 3화 「1부 마무리」 → 게임 1 엔딩 (각색 안내, 게임 2 예고) → **기억 노트 입력 화면** | 6화 에필로그 「두 개의 결말」 → 엔딩 화면 세 장 → **반박문 쓰기 입력 화면** |
| 판결 | **미결** | **유죄**, 그리고 독일 사회의 반성 |
| 메시지 단계 | 1·2단계 중심. 3단계는 "어쩔 수 없었다"라는 **질문**으로만 남긴다 | 1~3단계. 6화에서 3단계(악의 평범성)의 답을 낸다 |
| 끝난 뒤 활동 | **기억 노트** (11장): 게임 안에서 고르고 한 줄씩 써서 지금 내 생각을 남긴다 | **반박문 쓰기** (12장): 1차시 답을 불러와 다시 고른 뒤, 증거를 들어 친구에게 답장을 쓴다 |

**이 자리에서 나누는 이유**
- 1부는 "그런 일은 **없었다**"(사실 부정)와 싸우고, 2부는 "**어쩔 수 없었다**"(책임 축소)와 싸운다. 두 게임의 질문이 달라서 끊는 자리가 자연스럽다.
- 1부가 **미결**로 끝나는 불편함을 바로 설명으로 덮지 않고, 학생이 자기 말로 정리해 볼 시간을 준다.
- 기억 노트에 "어쩔 수 없었다"에 대한 **지금의 생각**을 적어 두면, 6화에서 악의 평범성을 본 뒤 **내 생각이 어떻게 바뀌었는지** 스스로 비교할 수 있다. 3단계 메시지를 교사가 말로 전하는 대신 학생이 직접 확인하게 된다.

**두 게임 사이에 이어지는 것**

두 게임은 게임 진행 데이터를 주고받지 않는다. 게임 2는 학생이 1부를 끝까지 했다고 보고 시작한다. 두 게임을 잇는 것은 GAS 시트에 저장된 **기억 노트 답** 하나뿐이다 (13장).

| 이어지는 것 | 게임 2에서 처리하는 방법 |
|---|---|
| 🟩 1부 선택 기록 (박영수, 후세 다쓰지) | 게임 2 시작 때 **기록 보관함**에 자동으로 넣는다. 6화 증언 4에서 다시 꺼내 쓴다 |
| 🟥 1부 피해 기록 | 법정 기록 목록에는 보이지 않게 저장해 두었다가 6화 에필로그 「기억의 벽」에 벽돌로 쓴다 |
| 1부 진범들의 "어쩔 수 없었다" | 게임 2 시작 화면(지난 기록)에서 한 번 보여 주고, 6화 전환 장면과 악의 평범성 장면에서 다시 보여 준다 |
| 하야시 (6화 임시 조수) | 지난 기록의 3화 카드에 얼굴을 넣어 6화에서 다시 나올 때 알아볼 수 있게 한다 |
| 조작 방법 | 4화 조사 파트와 첫 법정에 **조작 복습** 안내창을 띄운다 (1화 튜토리얼의 요약, 건너뛰기 가능) |
| 🟦 3화 증거 두 장 (일본 육군성 문서, 고노 담화) | 목록에 보이지 않게 불러 두었다가 반박문 쓰기 ④에서 쓴다 |
| 기억 노트 3번 답 | 반박문 쓰기 첫 화면에서 반과 번호로 GAS 시트에서 불러온다 |

- 2화를 건너뛴 반도 게임 2 보관함에는 박영수 기록이 들어간다. 6화에서 신중한이 🟩 기록마다 한 줄씩 설명하므로, 2화를 하지 않았어도 이해할 수 있다.
- 두 게임 사이에 시간이 벌어지거나 게임 1 때 결석한 학생이 있어도, 지난 기록과 조작 복습만으로 4화를 시작할 수 있게 한다.

## 3. 고정 등장인물

| 역할 | 인물 (가상) | 설명 |
|---|---|---|
| **주인공 (학생)** | 신참 변호사 **신중한** | 모든 사건에서 억울한 피고를 변호한다. 이름은 "신중한 변호사"로 읽히는 말장난이고, 정작 결정적인 순간에 자주 당황하는 신참이다. 한나는 "중한 씨"라고 부른다 |
| **조수** | 기자 **한나** | 힌트와 개념 설명을 맡는다. 6화에서는 직접 **피고**가 되고, 아렌트와 '악의 평범성'을 소개한다 |
| **라이벌 검사** | 검사 **레테** | 그리스 신화 속 '망각의 강'에서 따온 이름이다. 매번 **인터넷에 떠도는 왜곡 주장과 제국의 변명**을 그대로 말한다. 마지막에 "기억하는 사람이 있는 한… 나는 이길 수 없겠군"이라며 사라진다 |
| **재판장** | 재판장 | 모든 사건에서 같은 인물이다 |
| **임시 조수 (6화)** | 기자 **하야시** | 3화의 피고. 한나가 피고석에 서는 6화에서 조수를 맡는다 |

## 4. 전체 구성 한눈에 보기

> 1부 = 게임 1, 2부 = 게임 2 (2-6 참고)

| 부 | 화 | 제목 | 피고 (누명) | 처음에 불리해 보이는 이유 | 증인과 진범 | 깨는 왜곡 |
|---|---|---|---|---|---|---|

| 2부 | 6 | 명령서는 없다 | 한나 기자 | 히틀러가 서명한 학살 명령서가 발견되지 않음 | 1라운드 아이히만 → **히틀러** / 2라운드 크라우제 → **아이히만** | "경제를 살렸다", "합법", "명령서 없다", "애국자", "어쩔 수 없었다", "평범한 독일인은 책임 없다" |

### 부별 반전의 성격

| | 1부 일본 「심판받지 않은 자들」 | 2부 독일 「평범한 사람들」 |
|---|---|---|
| 레테의 전략 | "그런 일은 **없었다**" (사실 부정) | "**히틀러 한 명**의 일이다", "따른 사람은 **어쩔 수 없었다**" (책임 축소) |
| 반전 | 진범을 밝혀도 **실제 역사에서는 심판받지 않았다** | 명령한 히틀러와 **따른 사람들 모두** 책임이 있다 |
| 결말 | **미결** | **유죄**, 그리고 독일 사회의 반성 |

### 반복되는 변명: "어쩔 수 없었다"
히틀러와 모리 차관을 뺀 모든 진범이 같은 변명을 한다. 1~5화에서는 이름을 붙이지 않고 반복만 하다가, 6화에서 한나가 **"악의 평범성"** 이라는 이름을 붙인다. 학생들이 1부의 진범들까지 다시 보게 만드는 장치이며, 일본 편을 먼저 두는 이유이기도 하다.

| 1 | 오카다 감독관 | "어쩔 수 없었소!" |

## 5. 1부 일본 편 「심판받지 않은 자들」

> 교과서 연계: 189쪽(일본 군국주의), 196~199쪽(강제 동원, 일본군 '위안부', 도쿄 재판, 인권 회복 노력)
> 1부의 각 화는 **도쿄 재판의 한계**(교과서 198쪽)를 하나씩 드러낸다.

### 제1화 「군함도의 명부」 (튜토리얼)

**드러내는 도쿄 재판의 한계:** 관료와 기업인의 책임을 묻지 않았다.

**사건 브리핑**
- **오프닝:** 1944년, 하시마 해저 탄광의 3번 갱도가 무너진다.
- **피고:** **김석진(17세).** '모집'이라는 이름으로 마을에 인원이 할당되었고, 거부하자 순사가 찾아와 끌려왔다.
- **불리한 증거:** 🟦 회사의 사고 보고서("김석진이 작업을 고의로 방해했다"), 🟦 탈출 시도 기록(3개월 전 바다로 헤엄쳐 섬을 빠져나가려다 붙잡힘)
- **조사에서 만나는 사람:** 동료 광부 이봉수, 사고에서 구조된 광부 박만수

**증인과 진범:** 오카다 감독관 → 사토 광업소장 → **모리 차관** (군수성 고위 관료, 최종 진범)

**법정 흐름**

| 증언 | 정답 증거 | 드러나는 것 |
|---|---|---|
| 1 사고 당일 밤 (오카다) | 추궁 후 🟥 구조 기록 | 달아난 게 아니라 동료를 구하러 뛰어갔다 |
| 2 피고라는 사람 (오카다) | 🟥 동료의 증언과 치료 기록 | 탈출은 폭행과 굶주림 때문이었다 |
| 3 갱도 관리 (오카다) | 🟦 안전 점검 보고서, 썩은 버팀목 | 사고 원인은 김석진이 아니다 |
| 레테의 반격 | 🟥 동원 경위 기록 → 🟥 임금 명세서 | 스스로 온 것도, 정당한 노동도 아니었다 |
| 4 광업소의 방침 (사토) | 🟦 증산 명령서 | 무리한 증산 명령이 사고를 불렀다 |
| 5 도쿄의 사무실 (모리) | 🟦 동원 할당표 | 동원을 설계한 사람 |
| 6 국가를 위한 정책 (모리) | 🟦 국가 총동원법 | 최종 책임자 |

- **판결:** 김석진 무죄.
- **실제 역사 기록:** 모리 차관은 **기시 노부스케**가 모티브다. A급 전범 용의자로 체포되었지만 재판 없이 풀려났고, 1957년 일본 총리가 되었다. (교과서 198쪽)
- **튜토리얼 요소:** 추궁, 〔강조 단어〕, 증거 제시, 증거 카드 3종, 신뢰도

### 제2화 「두 개의 국적」 (선택 에피소드)

**드러내는 도쿄 재판의 한계:** 식민지 문제는 재판 대상이 아니었다.

**사건 브리핑**
- **오프닝:** 동남아시아의 연합군 포로수용소. 호주군 포로 톰슨 일병이 숨진다.
- **피고:** **박영수(20세).** '지원'이라는 이름으로 포로감시원이 되었다. 거부하자 가족의 배급을 끊겠다는 말을 들었다. **왼쪽 뺨에 길고 곧은 흉터**가 있다.
- **불리한 증거:** 🟦 1946년 판결 기록(포로 학대로 톰슨 일병을 숨지게 한 죄, 사형), 🟦 포로 진술 조서("그날 톰슨 앞에 막대기를 든 조선인 감시원이 서 있었다.")
- **조사에서 만나는 사람:** 동료 감시원 최동식, 호주군 군의관 웨스트 대위

**증인과 진범:** 해리스 상병 (피해자 쪽 증인) → **야마모토 중위**

**법정 흐름**

| 증언 | 정답 증거 | 드러나는 것 |
|---|---|---|
| 1 그날 작업장에서 (해리스) | **추궁**만으로 증언 추가 | 피해자 쪽 증인은 거짓말이 아니라 아직 다 말하지 못한 것 |
| 2 근무표 (야마모토) | 🟦 근무 일지 원본 | 근무표가 조작되었다 |
| 3 조선인 감시원 (야마모토) | 🟩 박영수의 치료 기록 | 박영수는 명령을 **거부하고** 맞았다 |
| 3-2 그 상처 (야마모토) | 🟦 박영수의 흉터 (증거 갱신) | 흉터는 야마모토의 칼집 끝 쇠 장식 자국 |
| 레테의 반격 | 🟦 모집 할당 문서 → 🟥 군속의 처지 | 스스로 선택한 것이 아니다 |
| 4 명령 (야마모토) | 🟥 포로들의 비밀 기록 | 진범은 야마모토 |

- **판결:** 박영수 무죄.
- **실제 역사 기록:** BC급 전범 재판에서 조선인 148명 유죄, 23명 사형. **"처벌받을 때는 일본인, 보상받을 때는 외국인이었습니다."**
- **교사용 메모:** 실제 조선인 포로감시원 중에는 가해에 가담한 사람도 있었다. 이 에피소드는 **누명**을 다룬 것이며, 박영수는 명령을 **거부한** 사람이므로 🟩 선택 기록이 된다.
- 시간이 부족하면 생략해도 1부의 흐름은 유지된다.

### 제3화 「첫 번째 보도」

**드러내는 도쿄 재판의 한계:** 일본군 '위안부' 문제를 본격적으로 다루지 않았다.

**사건 브리핑**
- **오프닝:** 1991년, 김학순 할머니의 증언을 처음 보도한 기사. 그리고 "날조 기자는 사과하라"는 항의가 쏟아진다.
- **피고:** **하야시 기자** (일본인, 가상 인물). 참전 군인 모임 회장 **다나카**(전 제38부대 소좌)에게 명예훼손으로 고발당했다.
- **불리한 증거:** 🟦 문제의 기사. 피해자가 끌려간 해를 "1942년"으로 적었지만, 녹음된 증언에서는 "1941년"이라고 말했다.
- **조사에서 만나는 사람:** 편집부장 기무라, 역사학자 오노 교수

**증인과 진범:** 기무라 편집부장 → **다나카 전 소좌** (온화한 인상. 전쟁 중 위안소를 관리했고, 패전 직전 관련 문서를 직접 불태웠다)

**반전의 핵심:** "증거가 없다"고 말하던 사람이 **증거를 없앤 사람**이었다.

**법정 흐름**

| 증언 | 정답 증거 | 드러나는 것 |
|---|---|---|
| 1 그 기사 (기무라) | 🟦 하야시의 취재 수첩 | 옮겨 적는 과정의 착오였다 |
| 레테의 반격 | 🟦 정정 기사 | 작은 착오는 날조가 아니다. 작은 오류로 전체를 부정하는 것이 부정론의 수법이다 |
| 증언 듣기 | (기록) 김학순 할머니의 실제 증언 | 피해자의 목소리 |
| 2 위안소 (다나카) | 🟥 일본군 위안소 분포도 (교과서 197쪽) | 아시아 전역에 있었다 |
| 3 민간 업자 (다나카) | 🟦 일본 육군성 문서 (1938) | 군이 업자를 고르고 통제했다 |
| 레테의 반격 | 🟦 고노 담화 (1993) | 일본 정부 스스로 군의 관여를 인정했다 |
| 4 명령서 (다나카) | 🟦 문서 소각 명령 → "다 태웠는데…" 실언 | 문서가 없는 이유 |
| 4-2 소각 (다나카) | 🟦 소각 담당자 명단 → 🟦 고발장 → 🟩 후세 다쓰지 | 태운 사람은 다나카. 같은 시대의 일본인도 다른 선택을 했다 |

- **판결:** 하야시 기자 무죄.
- **실제 역사 기록:** 1992년 넉 달 만에 155명이 피해를 신고했다. 등록 피해자는 240명이다. 생존자는 2015년 46명에서 2026년 **5명**으로 줄었다. 증거를 태운 사람처럼, 일본 정부는 지금 **증언이 사라지기를 기다리고 있다.** 8월 14일은 '일본군 위안부 피해자 기림의 날'이다.
- **표현 원칙:** 김학순 할머니는 게임 캐릭터로 등장하지 않고, 교과서에 실린 **실제 증언 한 문장**으로만 나온다. 처음에 의심받는 것은 **기자의 기사 속 착오**이며, 피해자의 증언을 의심하게 만드는 장면은 없다.

### 1부 마지막 장면과 게임 1 엔딩 (3화 끝)
진범을 모두 찾았지만, 실제 역사에서 이들은 심판받지 않았다. 1부는 **「심판받지 않은 자들」, 미결**로 끝난다. 주인공은 오카다도, 사토도, 야마모토도, 다나카도 똑같은 말을 했다는 것을 떠올린다. **"어쩔 수 없었다."** 한나는 "그 말은 일본에서만 나온 게 아니에요"라는 말을 남긴다.

이어서 **게임 1 엔딩**이 나온다.
- 화면 1: 각색 안내. 1부의 가상 인물과 실제 역사를 구분해 알린다. (6화 엔딩의 각색 안내와 같은 형식)
- 화면 2: 게임 2 예고 「제2부 「평범한 사람들」 / 제4화 「숨겨진 방」」. 멀리서 들리던 기차 바퀴 소리가 가까워진다.
- 이어서 **기억 노트 입력 화면**(11장)으로 넘어가고, 답을 저장하면 게임 1이 끝난다.

## 6. 2부 독일 편 「평범한 사람들」

> 교과서 연계: 189쪽(나치즘, 『나의 투쟁』), 196~197쪽(홀로코스트), 198~199쪽(뉘른베르크 재판, 독일의 반성, 독일 교과서 서술 변화)
> 게임 2는 4화 앞의 **게임 2 시작 화면**으로 연다. 이어서 **2부로 넘어가는 장면 「같은 전쟁, 다른 법정」**이 나온다. 4~6화는 **레비 가족** 한 가족의 이야기로 이어진다.

| 화 | 다루는 시기 | 초점 |
|---|---|---|

| 6화 | **책임** (1961) | 명령한 히틀러, 따른 사람들 |

### 게임 2 시작 화면 (4화 앞)
1. **타이틀:** 「기억의 법정 게임 2 / 제2부 「평범한 사람들」」
2. **지난 기록:** 한나가 1부 세 사건을 기록 카드 세 장으로 짧게 되짚는다. 각 카드에는 피고, 진범, 실제 역사의 결말(심판받지 않음)을 한 줄씩 적는다. 3화 카드에는 하야시의 얼굴을 넣는다.
3. **1부 기록 불러오기:** 🟩 박영수의 치료 기록, 🟩 후세 다쓰지가 기록 보관함(한나의 초록 서랍)에 들어간다. 1부의 🟥 피해 기록은 법정 기록 목록에 보이지 않게 저장해 두었다가 6화 「기억의 벽」에 쓰고, 🟦 일본 육군성 문서와 🟦 고노 담화도 같은 방식으로 저장해 두었다가 반박문 쓰기 ④에 쓴다.
4. **1부 마지막 장면 회상:** 1부 진범들의 "어쩔 수 없었다"와 한나의 "그 말은 일본에서만 나온 게 아니에요"를 다시 보여 주고, 「같은 전쟁, 다른 법정」으로 넘어간다.
5. **조작 복습:** 4화 조사 파트 시작(증거 3종, 법정 기록)과 첫 법정(추궁, 증거 제시, 신뢰도)에 1화 튜토리얼을 줄인 안내창을 띄운다. [건너뛰기]로 넘길 수 있다.

### 제4화 「숨겨진 방」

**사건 브리핑**
- **오프닝:** 1943년 새벽, 빵집 다락방 문이 부서지고 레비 가족이 끌려간다.
- **피고:** **마르타 슈미트.** 동네 빵집 주인. 레비 가족을 다락방에 숨겨 주었다. 1946년, 레비 가족을 비밀경찰에 **밀고했다는 누명**으로 재판을 받는다.
- **불리한 증거:** 🟦 목격자 진술(체포 전날 마르타가 비밀경찰 건물로 들어감), 🟦 밀고 편지(서명란에 **고리 모양으로 말린 "S"**. 레테: "마르타 슈미트의 S다"), 🟦 은식기 발견 기록(마르타의 집에서 레비 가족의 은식기가 나옴). 다락방을 아는 사람은 마르타뿐이었다.

**증인과 진범**
- **진범: 슈나이더(Schneider).** 레비 가족의 옆집 시계방 주인. 조사 단계에서는 **친절한 조력자**로 보인다.
- **가짜 용의자: 슈바르츠(Schwarz) 부인.** 무섭고 냉랭한 나치당 구역 감시원. 학생들이 먼저 의심하게 된다.

**법정 흐름**

| 증언 | 정답 증거 | 드러나는 것 |
|---|---|---|
| 레테의 주장 「숨을 이유」 | 🟦 뉘른베르크 인종법 (1935) → 🟥 수정의 밤 (1938) | 국가가 법과 폭력으로 유대인을 몰아냈다 |
| 1 그날 오후 (슈나이더) | 🟦 비밀경찰 소환장 | 마르타는 조사를 받으러 불려 간 것이다 |
| 레테의 반격 「은식기」 | 🟥 레아의 일기 (첫 번째 공책) | 훔친 것이 아니라 맡겨진 것이다 |
| 2 이웃 (슈나이더) | 🟦 1938년 동네 유대인 재산 매각 기록 | 슈나이더는 유대인 재산으로 이득을 본 사람 |

| 레테의 반격 「시민의 의무」 | 🟩 '열방의 의인' (마르타 자신, 오스카 쉰들러) | 같은 법 아래에서도 다른 선택을 한 사람이 있었다 |
| 증언 듣기 | 레아의 일기, 안네 프랑크의 일기 | 또래 소녀가 겪은 은신 생활 |

- **판결:** 마르타 무죄.
- **실제 역사 기록:** 평범하고 친절한 이웃들이 유대인을 신고하고 재산을 넘겨받았다. 한편 목숨을 걸고 유대인을 숨긴 사람들도 있었다. '열방의 의인' 가운데 독일인은 600명이 넘으며, 오스카 쉰들러는 약 1,200명을 구했다.
- **다음 화로 넘기는 장면:** 적십자에서 편지가 온다. *"다비드 레비, 생존 확인."*
- **다루지 않는 것:** 수용소 안의 모습은 5화에서 다룬다.

### 제5화 「아버지의 시계」

**사건 브리핑**
- **오프닝:** 1946년, 난민 수용소에서 한 청년이 '도둑'으로 체포된다.
- **피고:** **다비드 레비(18세).** 가족 중 유일한 생존자. 왼팔에 수감 번호 **104732** 문신이 있다. 고향에 돌아와 시계점 진열장에서 **아버지의 시계**를 보고, 가게에 들어가 보여 달라고 부탁했을 뿐이다. **시계에 손도 대지 않았다.**
- **불리한 증거:** 🟦 베커의 신고("금시계가 사라졌다. 전날 그 시계를 탐내던 유대인 청년이 있었다. 1930년대부터 내려온 가보다."), 🟦 수색 기록(다비드의 가방에서 "베커 상회 기증" 도장이 찍힌 새 담요에 싸인 금시계가 발견됨)
- **조사에서 만나는 사람:** 점원 프리츠, 같은 수용소 생존자 야코프

**증인과 진범**
- **진범: 베커(Becker).** 시계점 주인이자 마을 유지. 난민에게 담요를 기부하는 너그러운 인물로 보인다. 정체는 아우슈비츠 소지품 창고('캐나다')를 맡았던 친위대원이며, **시계를 귀에 대 보는 버릇**이 있다. 담요에 시계를 **몰래 넣어** 다비드에게 누명을 씌웠다.
- **가짜 용의자:** 점원 프리츠, 정체를 알 수 없는 "회색 외투의 남자"

**의심이 옮겨 가는 흐름**

| 단계 | 학생이 의심하는 사람 | 이유 |
|---|---|---|
| 면회 | 다비드 | 가방에서 시계가 나옴 |
| 조사 | 프리츠, 회색 외투의 남자 | 프리츠는 열쇠가 있고 불안해 보임. 야코프가 정체 모를 남자를 봄 |
| 증언 3 | **베커** | 담요 한 장을 따로 챙겼고, 시계를 귀에 대는 버릇이 회색 외투의 남자와 같음 |
| 증언 5 | 베커의 정체 | 아우슈비츠 '캐나다' 창고의 친위대원 |

**법정 흐름**

| 증언 | 정답 증거 | 드러나는 것 |
|---|---|---|
| 1 그날 밤 (베커) | 🟦 난민 수용소 출입 명부 | |
| 2 담요 배달 (프리츠) | 🟦 수색 기록 → 🟦 야코프의 이야기 | 프리츠는 누명. 회색 외투의 남자가 있었다 |
| 3 그날 아침 (베커) | 🟦 담요 배달 전표 → 🟦 야코프의 이야기 | 회색 외투의 남자는 베커 |
| 4 가보 (베커) | 금시계 확대: 뒷면 각인 "J. Levi 1920" | 원래 레비 가족의 시계다 |
| 레테의 반격 「암시장」 | 🟦 소지품 압수 목록 | 수용소에 도착하던 날 빼앗긴 시계. 맨 아래에 "베를린 IV B4과" 도장 |
| 레테의 주장 「노동 수용소」 | 🟥 아우슈비츠 정문 사진 → 🟥 홀로코스트 희생 기록 | 노동 수용소가 아니라 학살이었다 |
| 증언 듣기 | 다비드의 증언 | 수용소에서 겪은 고통 |
| 레테의 반격 「여러 사람의 손」 | 증거 없음 → 휴정, 🟦 친위대 인사 기록 발견 | |
| 5 전쟁 중에 (베커) | 🟦 친위대 인사 기록 | 베커의 정체 |
| 레테의 반격 「물건만 분류했다」 | 🟥 신발과 가방 더미 | 물건의 주인들이 어디로 갔는지 알고 있었다 |

- **판결:** 다비드 무죄. 아버지의 시계를 돌려받는다.
- **에필로그:** 마르타가 맡아 두었던 레비 가족의 은식기를 다비드에게 돌려준다.
- **실제 역사 기록:** 아우슈비츠에서만 약 110만 명이 목숨을 잃었다. 홀로코스트로 유럽 유대인 약 600만 명, 곧 세 명 중 두 명이 희생되었다. 1월 27일은 '국제 홀로코스트 희생자 추모의 날'이다. 아우슈비츠 친위대원 수천 명 가운데 재판을 받은 사람은 일부뿐이었다.
- **다음 화로 넘기는 장면:** 슈나이더는 신고만 했고, 베커는 물건만 분류했다. **그럼 이 열차는 누가 보낸 걸까?**
- **표현 원칙:** 가스실과 시신은 직접 보여 주지 않는다. 증언, 유품, 기록, 숫자로 전한다. 5화에는 🟩 선택 기록이 없다.

### 제6화 「명령서는 없다」 (최종화)

**사건 브리핑**
- **오프닝:** 1961년 예루살렘. 방탄유리 부스 안에 평범한 공무원처럼 보이는 남자가 앉아 있다. 아이히만 재판이다.
- **피고:** **한나 기자.** 지금까지 함께한 조수가 피고석에 서고, 3화의 하야시 기자가 임시 조수를 맡는다. 한나는 아이히만 재판을 취재하고 **"홀로코스트는 ① 히틀러가 명령하고 ② 수많은 사람이 실행한 일이다"** 라는 기사를 썼다가 '날조 보도'로 고발당했다.
- **불리한 증거:** [검찰 측 증거] 명령서 조사 결과. **히틀러가 서명한 유대인 학살 명령서는 한 장도 발견되지 않았다.**
- **핵심:** 한나의 기사에는 잘못이 없다. 레테는 **"기록이 없다"를 "그런 일이 없었다"로 바꿔치기**한다. 실제 홀로코스트 부정론자들이 쓰는 수법이다.
- **의뢰:** *"중한 씨, 이번엔 제가 부탁할게요. 제 기사가 거짓이 되면, 지금까지 우리가 모은 기록도 전부 거짓이 돼요."*

**재판 구조**

| | 1라운드 | 2라운드 |
|---|---|---|
| 질문 | 명령한 자는 잘못했는가? | 따른 자는 어쩔 수 없었는가? |
| 증인 | 아이히만 → **히틀러** (진범) | 크라우제 → **아이히만** (진범) |
| 증명하는 기사 내용 | ① 히틀러가 명령했다 | ② 수많은 사람이 실행했다 |
| 메시지 단계 | 2단계 | 3단계 (악의 평범성) |
| 판결 | 히틀러 **유죄** (기억의 법정이 처음으로 판결) | **"1961년 예루살렘 판결은 옳았다"** |

**아이히만을 다시 재판하지 않는다.** 그는 1961년에 이미 재판을 받았다. 이 법정에서는 기록 속 증인일 뿐이며, 처음 등장할 때 재판장이 "이 법정이 묻는 것은 증인의 죄가 아니라 피고의 기사가 사실인지"라고 밝힌다.

**1라운드: 명령한 자**

| 증언 | 정답 증거 | 드러나는 것 |
|---|---|---|
| 1 명령서 (아이히만) | 3번 추궁 → 🟦 한나의 취재 수첩 | 아이히만 스스로 "총통께서 유대인의 육체적 절멸을 명령하셨다"고 말했다 |
| 2 기록 속의 목소리 (히틀러) 1번 "경제를 살렸다" | 🟦 나치 경제의 실체 | 군비 확장, 빚, 유대인 재산 약탈. 결과는 독일인 수백만 명의 죽음 |
| 2번 "선거로 뽑힌 합법적 지도자" | 🟦 수권법과 독재 (1933) | 선거로 얻은 권력으로 선거를 없앴다 |
| 3번 "나의 명령서는 없다" | 🟦 T4 작전 명령서 → 🟦 1939년 국회 연설 | 직접 서명한 살해 명령서가 있고, "유럽 유대인의 절멸"을 예고했다 |
| 4번 "독일을 사랑한 애국자" | 🟦 네로 명령 (1945) | 마지막에는 자기 국민까지 버렸다 |
| 레테의 반격 「명령서는 없다」 | 🟦 어빙 대 립스탯 재판 판결 (2000) | 같은 주장을 한 사람은 실제 법정에서 졌다 |

- **1라운드 판결:** 히틀러 유죄. "살아서 어떤 법정에도 서지 않았으므로, 기억의 법정이 처음으로 판결합니다."
- **실제 역사 기록:** 히틀러는 1945년 4월 30일 자살해 **끝내 법정에 서지 않았다.** (1부의 모리 차관과 짝을 이루는 장면)

**전환 장면 「그게 끝이 아니었다」**
- 레테: *"히틀러는 유죄요. 그러니 이제 끝났소. 나머지는 명령을 따랐을 뿐이오."*
- 재판장이 끝내려는 순간 한나가 일어난다. *"아직 끝나지 않았어요. 제 기사의 절반만 증명됐어요. 히틀러 혼자서 600만 명을 죽일 수는 없었어요."*
- 1~5화 진범들의 "어쩔 수 없었다"가 차례로 들려온다.

**2라운드: 따른 자**

| 증언 | 정답 증거 | 드러나는 것 |
|---|---|---|

- **2라운드 결론:** 1961년 예루살렘 판결문을 다시 보여 준다. ("명령에 따랐을 뿐"이라는 주장을 받아들이지 않는다. 명백히 불법인 명령은 따를 의무가 없다. 사형.) 이어서 기억의 법정이 **"1961년 예루살렘 판결은 옳았다"** 고 선언한다.
- **레테의 반격 「평범한 독일인」:** 🟦 독일 역사 교과서 서술의 변화. 1953년 "힘러가 하였다" → 1998년 "공범자가 되었다" (교과서 199쪽)

**악의 평범성**
1. **한나의 설명:** 괴물이 올 줄 알았는데, 거기 앉아 있는 건 평범한 공무원이었다. 그는 한 번도 "이게 옳은 일인가?" 생각하지 않았다.
2. **1~6화 진범 몽타주:** 감독관, 장교, 이웃, 가게 주인, 경찰, 공무원. 모두 같은 말을 했다. **"어쩔 수 없었다."**
3. **오해를 막는 한 문장 (중요):** *"평범하다는 건 죄가 가볍다는 뜻이 아니에요."* 아렌트의 말 **"정치에서 복종과 지지는 같은 것이다."**

**최종 변론과 판결:** 기사 ①과 ②가 모두 사실로 증명되어 **한나 무죄.** 판결은 히틀러 유죄 → 1961년 예루살렘 판결 확인 → 한나 무죄 순서로 나온다.

**실제 역사 기록**
- 아이히만은 1961년 12월 사형을 선고받고 1962년 6월 처형되었다. 예루살렘 법원은 "명령을 따랐을 뿐"이라는 주장을 받아들이지 않았다.
- 서독은 1960년대부터 스스로 나치 관련자를 재판했다. (프랑크푸르트 아우슈비츠 재판)
- 1970년 브란트 총리가 바르샤바에서 무릎을 꿇었다.
- 독일 교과서 서술이 바뀌었다.
- 2000년 어빙 판결: 명령서가 없다는 것은 홀로코스트가 없었다는 증거가 될 수 없다.

**히틀러 연출 원칙 (중요)**
- **흑백**, 작은 체구로 앉아 있는 모습만 그린다. 표정은 무표정과 굳음 두 가지뿐이다.
- 연설 장면, 나치 상징, 행진 장면, 웅장한 음악은 쓰지 않는다.
- 대사는 **레테가 건넨 종이를 읽는** 옹호 논리뿐이고, 모든 문장은 증거로 반박된다.
- 무너지는 장면은 초라하게, 밈이 될 만한 장면은 만들지 않는다.

## 8. 연출 원칙과 금지선

### 피해자를 다루는 원칙
- **실존 피해자의 대사는 지어내지 않는다.** 김학순 할머니는 교과서에 실린 실제 증언만 인용하고, 캐릭터로 등장시키지 않는다.
- 실존 피해자를 **피고로 세우지 않는다.** 피고는 모두 가상 인물이다.
- 처음에 불리한 증거는 피고의 행동이나 서류에서 나온다. **피해자의 증언을 의심하게 만드는 방식은 쓰지 않는다.**
- **참혹한 이미지는 쓰지 않는다.** 가스실, 시신은 그리지 않는다. 지도, 문서, 유품, 기념관 사진처럼 교과서 수준의 자료만 쓴다.
- 🟥 피해 기록을 **잘못 제시해도 신뢰도가 깎이지 않는다.**
- 피해 증언은 **'증언 듣기'** 장면으로, 선택지 없이 끝까지 듣게 한다.

### 왜곡 주장을 다루는 원칙
- 레테가 말하는 왜곡 주장은 **반드시 그 장면 안에서 반박된다.** 반박되지 않은 채 끝나는 왜곡은 하나도 없다.
- 실제 인터넷 밈, 짤, 영상은 게임에 쓰지 않는다.
- **나치 상징**(하켄크로이츠, 독수리 문장)은 문서와 배경에도 쓰지 않는다.

### 혐오로 흐르지 않게 하는 원칙
- 메시지는 "일본인, 독일인이 나쁘다"가 아니라 **"제국주의와 그것을 따른 선택이 잘못이다"** 이다.
- 🟩 선택 기록에 **일본인(후세 다쓰지), 독일인(마르타, 쉰들러, 101대대의 12명), 조선인(박영수)** 을 넣어 나라가 아니라 선택의 문제임을 보여 준다.

### 인물과 사실
- 등장인물 대부분은 **가상 인물**이고, 증거는 **실제 사료**를 쓰며 출처를 표기한다.
- 실존 인물(기시 노부스케 모티브, 김학순, 후세 다쓰지, 오스카 쉰들러, 한나 아렌트, 아이히만, 히틀러)은 실제 기록과 발언을 바탕으로만 쓴다.
- 사실, 비판, 해석을 구분해서 쓴다.
- 역전재판의 캐릭터 그림, 음악, 음성 등 **원작의 저작물은 쓰지 않는다.** 게임 구조만 빌린다.

## 10. 수업 운영안 (2차시)

| 차시 | 게임 | 끝난 뒤 활동 (게임 안 입력 화면) |
|---|---|---|
| 1 | 게임 소개 + **게임 1** (1화 → 3화. 2화는 선택) | **기억 노트** (약 10분, 11장) |
| 2 | **게임 2** (게임 2 시작 화면 → 4화 → 6화 + 에필로그) | **반박문 쓰기** (약 10분, 12장) + 우리 반 결과 보기 |

- **2인 1조**로 게임을 한다. 한 명은 조작하고, 한 명은 증거를 읽는다. "이게 모순 아니야?"라는 대화가 자연스럽게 생긴다.
- 쓰기 활동은 **한 사람씩** 한다. 짝이 기기 하나를 같이 쓰면 차례로 쓴다(저장하면 [짝도 쓰기] 버튼이 나온다). 1인 1기기라면 각자 타이틀 화면의 [쓰기 활동 바로 가기]로 들어간다. 결석한 학생이 나중에 쓸 때도 이 버튼을 쓴다.
- 쓰기 활동 10분은 꼭 남긴다. 특히 기억 노트는 반드시 게임 2를 하기 **전에** 써야 한다. 6화를 본 뒤에 쓰면 처음 생각과 바뀐 생각을 비교할 수 없다.
- **분량 점검 (결정 필요):** 앞선 운영안에서는 1화 하나를 약 35분으로 잡았다. 이 기준으로 어림하면 지금 대본은 게임 1(1화, 3화)이 약 70분, 게임 2(4~6화)가 2시간이 넘는다. 한 차시에 넣으려면 대본을 줄이거나, 블록 수업처럼 차시를 길게 잡아야 한다. 시범 플레이로 실제 시간을 먼저 재 본다.
- 교과서 213쪽 창의·융합 활동 대신 활용할 수 있다.

## 11. 기억 노트 (게임 1이 끝난 뒤, 약 10분)

게임 1 엔딩 바로 뒤에 나오는 **게임 안 입력 화면**이다. 1부에서 본 것과 **지금의 내 생각**을 짧게 남긴다. 답은 GAS로 구글 시트에 저장되고(13장), 3번 답은 2차시 반박문 쓰기 때 다시 불러온다.

'판결문을 써 보세요' 같은 어려운 질문은 하지 않는다. **고르기 위주**로 하고, 직접 쓰는 칸은 **한 줄짜리 두 칸**뿐이다. '미결'처럼 꼭 필요한 말은 쉬운 말로 풀어서 알려 준다.

**화면 순서**

| 화면 | 학생에게 보이는 말 | 입력 방식 |
|---|---|---|
| 0 | "기억 노트를 쓸 차례예요. 반과 번호, 이름을 넣어 주세요." | 반, 번호 (고르기), 이름 (입력) |
| 1 | "1부에서 가장 기억에 남는 증거를 **제시**해 주세요." | 1~3화에서 얻은 증거 카드 가운데 한 장 고르기 (게임의 증거 제시와 같은 방식) |
| 1-2 | "왜 기억에 남았나요?" | 버튼 고르기 (여러 개 가능): 처음 알았다 / 슬펐다 / 화가 났다 / 놀라웠다 / 억울했다. 한 줄 더 쓰기는 **선택** |
| 2 | "1부에서 **진짜 잘못한 사람**은 누구일까요? 한 명을 골라 주세요." | 얼굴 버튼: 오카다 (탄광 감독관), 사토 (광업소장), 모리 (차관), 야마모토 (중위), 다나카 (소좌). 2화를 하지 않았으면 야마모토는 나오지 않는다 |
| 2-2 | "이 사람이 한 잘못을 한 줄로 써 주세요." | **한 줄 쓰기 (필수).** 흐린 예시 글씨: "～을 시켰다", "～을 숨겼다" |
| 2-3 | "이 사람은 실제로 벌을 받았을까요?" | 받았다 / 받지 않았다. 고르면 바로 알려 준다: "받지 않았어요. 1부의 진범들은 아무도 벌을 받지 않았어요. 그래서 1부의 판결은 **'미결'**, 아직 끝나지 않은 사건이에요." |
| 3 | "진범들은 모두 **'어쩔 수 없었다'**고 말했어요. 여러분 생각은 어때요?" | 버튼 셋: 맞다, 어쩔 수 없었을 것 같다 / 잘 모르겠다 / 아니다, 다르게 할 수 있었다 |
| 3-2 | "왜 그렇게 생각했나요? 한 줄이면 충분해요." | **한 줄 쓰기 (필수)** |
| 끝 | "기억 노트를 저장했어요. 정답은 없어요. 게임 2가 끝나면 다시 물어볼게요." | [짝도 쓰기] / [끝내기] |

**운영 원칙**
- **3번에는 정답을 알려 주지 않는다.** 화면에도 피드백이 없고, 교사도 이 시간에는 반박하지 않는다. 그 답은 6화에서 학생이 스스로 찾게 한다. 3단계는 2단계를 확실히 끝낸 뒤에 다룬다는 원칙(1-2)과 같은 이유다. "왜 그렇게 생각했어?"라고 되묻는 정도는 괜찮다.
- **2-3번은 반대로 바로 알려 준다.** '미결'을 설명하는 가장 짧은 방법이다.
- 3번은 **점수를 매기지 않는다.** 점수가 걸리면 학생들이 "정답처럼 보이는 답"을 골라, 나중에 생각이 어떻게 바뀌었는지 볼 수 없다.
- 한 줄 쓰기 칸은 빈칸일 때만 넘어가지 못하게 하고, 길이나 맞춤법은 따지지 않는다.

## 12. 반박문 쓰기 (게임 2가 끝난 뒤, 약 10분)

게임 2 엔딩 바로 뒤에 나오는 게임 안 입력 화면이다. 학생에게는 "반박문" 대신 **"친구에게 답장하기"** 라고 부른다. 먼저 1차시 기억 노트의 3번 답을 불러와 다시 고르게 하고, 그다음 게임에서 본 증거로 친구의 말에 답장을 쓴다.

**화면 순서**

| 화면 | 학생에게 보이는 말 | 입력 방식 |
|---|---|---|
| 0 | "반과 번호, 이름을 넣어 주세요." | 반, 번호, 이름. 넣으면 1차시 기억 노트를 불러온다 (13장) |
| 1 | "1차시의 나는 이렇게 생각했어요." (1차시에 고른 답과 이유를 그대로 보여 준다) "지금 다시 고른다면?" | 버튼 셋 (기억 노트 3번과 같음). 1차시 기록이 없으면 "1차시 기록이 없어요"라고 알리고 그냥 고르게 한다 |
| 1-2 | "왜 그렇게 생각했나요?" | **한 줄 쓰기 (필수)** |
| 2 | "친구가 단톡방에 이런 말을 올렸어요. 하나를 골라 답장해 보세요." | 메시지 넷 가운데 하나 고르기 (아래 표) |
| 2-2 | "이 말이 틀렸다는 증거를 **제시**하세요." | 그 메시지에 맞는 증거 카드 3~4장 가운데 한 장 고르기. 고르면 카드 내용이 옆에 펼쳐진다 |
| 2-3 | 답장 틀 채우기 | **한 줄 쓰기 두 칸 (필수)** |
| 끝 | "답장을 저장했어요. 이제 여러분이 증인이에요." | [짝도 쓰기] / [끝내기] |

**답장 틀 (2-3)**
> 그 말은 사실이 아니야.
> 〔고른 증거 이름〕을 보면, ______________. ← 증거가 보여 주는 사실
> 그러니까 ______________. ← 내 생각

**메시지와 고를 수 있는 증거**

| 메시지 | 고를 수 있는 증거 |
|---|---|
| ① "히틀러가 경제 살렸잖아" | 🟦 나치 경제의 실체, 🟦 네로 명령 (1945), 🟥 홀로코스트 희생 기록 |
| ② "히틀러 명령서도 없다던데?" | 🟦 T4 작전 명령서 (1939), 🟦 1939년 국회 연설, 🟦 한나의 취재 수첩, 🟦 어빙 대 립스탯 재판 판결 (2000) |
| ③ "그 시대엔 다들 어쩔 수 없었잖아" | 🟩 101 예비경찰대대 기록 (1942), 🟩 박영수의 치료 기록, 🟩 후세 다쓰지, 🟩 '열방의 의인' 기록 |
| ④ "위안부는 돈 벌러 간 거라던데?" | 🟦 일본 육군성 문서 (1938), 🟦 고노 담화 (1993), 🟥 김학순 할머니의 공개 증언 기록 |

- 메시지마다 **맞는 증거만** 보여 준다. 틀린 증거를 고를 일이 없게 해서, 학생이 쓰기에만 집중하게 한다.
- ③은 기억 노트 3번과 이어진다. ④는 1부 내용이라, 게임 2 시작 때 이 카드들을 함께 불러 둔다 (2-6).
- 시간이 남으면 교사가 말로 묻는다: "다들 그러니까 나도 따라 했어"라는 말은 괜찮을까? (입력하지 않는다)
- **우리 반 결과 보기:** 교사가 구글 시트의 「요약」 탭을 화면에 띄워, 이름 없이 "어쩔 수 없었다"에 대한 1차시와 2차시의 답이 어떻게 달라졌는지 보여 준다.

**살펴볼 점:** 증거를 넣어 썼는가 / 누가 잘못했는지 분명하게 썼는가

## 13. 쓰기 활동의 GAS 연동

게임은 두 쓰기 활동의 답을 GAS(구글 앱스 스크립트) 웹 앱으로 보내 구글 시트에 저장하고, 2차시에는 1차시 답을 불러온다.

**웹 앱이 하는 일**
1. **저장:** 기억 노트나 반박문 답 한 건을 해당 시트에 한 줄로 덧붙인다.
2. **불러오기:** 반과 번호를 받아, 그 학생의 가장 최근 기억 노트 3번 답(고른 것, 이유)을 돌려준다.

**시트 구성**

| 시트 | 열 |
|---|---|
| 기억노트 | 제출 시각, 반, 번호, 이름, 2화 여부, 기억에 남은 증거, 기억에 남은 이유(버튼), 기억에 남은 이유(한 줄), 잘못한 사람, 그 사람의 잘못, 벌을 받았을까, 어쩔 수 없었다(선택), 어쩔 수 없었다(이유) |
| 반박문 | 제출 시각, 반, 번호, 이름, 1차시 선택(불러온 값), 2차시 선택, 2차시 이유, 고른 메시지, 제시한 증거, 답장 빈칸 1, 답장 빈칸 2 |
| 요약 | 반마다 "어쩔 수 없었다" 세 답의 수를 1차시와 2차시로 나란히 센다 (수식으로 자동 계산). 이름은 나오지 않는다 |

- 같은 학생이 여러 번 내면 모두 남기고, 불러오기와 요약에는 **가장 최근 것**을 쓴다.
- 학생 정보는 반, 번호, 이름만 받는다. 시트는 교사의 학교 계정에 두고, 학기가 끝나면 지운다.
- 저장에 실패하면 [다시 보내기]를 띄운다. 계속 실패하면 쓴 답을 화면에 그대로 보여 주어, 써 둔 답이 사라지지 않고 교사가 확인할 수 있게 한다.
- **구현 메모:** 게임을 GAS 웹 앱(HtmlService)으로 배포하면 `google.script.run`으로 바로 부른다. 게임을 다른 곳(예: GitHub Pages)에 두면 저장은 POST, 불러오기는 GET으로 부르고, POST 본문은 `text/plain`으로 보낸다. `application/json`으로 보내면 브라우저가 사전 요청(CORS preflight)을 보내는데, GAS 웹 앱은 이를 처리하지 못한다.

## 15. 교사용 사실 확인 메모

- **기시 노부스케:** 교과서 198쪽은 "A급 전쟁 범죄자 가운데 한 명은 일본 수상이 되기도"라고 쓰지만, 정확히는 **A급 전범 용의자로 체포되었다가 기소되지 않고 석방**(1948)된 인물이다.
- **BC급 전범:** 조선인 148명 유죄, 23명 사형. 1952년 이후 일본 국적을 잃어 보상에서 제외되었다.
- **1938년 일본 육군성 문서:** 1992년 요시미 요시아키가 발견했고, 1993년 고노 담화로 이어졌다.
- **'위안부' 피해자 수:** 등록 240명, 2026년 현재 생존자 5명. **수업 전에 최신 숫자를 다시 확인할 것.**
- **히틀러 서명 명령서:** 홀로코스트에 대한 히틀러의 서명 명령서는 발견되지 않았다. 게임에서는 T4 작전 승인서, 1939년 연설, 실행자들의 진술로 책임을 증명한다.
- **어빙 대 립스탯 재판:** 2000년 4월 영국 고등법원 판결. 관련 영화 「나는 부정한다」(2016)는 관람 등급 확인 뒤 활용.
- **아이히만 재판:** 1961년 12월 사형 선고, 1962년 6월 1일 집행. 게임 속 판결문은 요지를 줄여 옮긴 것이다.
- **반제 회의:** 1942년 1월 20일, 15명, 약 90분. 회의록은 아이히만이 작성했다.
- **헝가리 유대인 수송:** 1944년 5~7월, 약 43만 명.
- **비슬리체니 증언:** 1946년 뉘른베르크 재판.
- **101 예비경찰대대:** 크리스토퍼 브라우닝, 『아주 평범한 사람들』. 1942년 7월 유제푸프. 크라우제는 가상 인물이다.
- **아우슈비츠:** 번호 문신은 아우슈비츠에만 있었다. 소지품 창고는 '캐나다'라고 불렸다.
- **악의 평범성 반론 (심화):** 베티나 슈탕네트(2011)는 아이히만이 '평범한 관료'를 연기했다고 주장했다. "평범해 보인다는 것도 변명이 될 수 없다"는 토론으로 활용할 수 있다.

## 16. 작업 순서

4. **대본을 바탕으로 필요한 스프라이트 시트 정리**
   - **게임 1, 게임 2로 나누어** 정리한다.
   - 두 게임에 모두 나오는 것은 따로 표시한다: 신중한, 한나, 레테, 재판장, 하야시(3화, 6화), 1부 진범 얼굴(6화 몽타주), 기억의 법정 배경들, 🟩 1부 기록 카드
5. 스프라이트 시트에 맞는 그림 제작 프롬프트 작성
6. 하나씩 만들기 (그림 파일은 `assets/characters`, `assets/backgrounds`, `assets/evidence`)
7. 기억 노트, 반박문 쓰기 입력 화면과 GAS 웹 앱 만들기 (11~13장)
