## 2. 고친 것 (이미 끝남)

**원인:** 예전에는 외침이 나올 때마다 `<audio>`를 새로 만들어 파일을 열고 풀어서 틀었다. 그래서 그림보다 늦게 났다. 소리 파일 앞에 무음이 있으면 그만큼 더 늦게 들린다.

**고친 방법** (`game/js/core.js` 소리 부분, `game/data/common.js`의 `DATA.소리.바로틀기`)
- 학생이 처음 화면을 누를 때(`G.audio.unlock()`) 외침 소리 3개를 Web Audio로 미리 풀어 둔다.
- 외침 그림이 뜰 때 미리 풀어 둔 소리를 바로 튼다.
- 파일 앞의 소리 없는 부분(약 -40dB 아래)은 저절로 건너뛴다.
- 폴더째 열 때(file://)는 파일을 직접 읽을 수 없어서, 미리 불러 둔 `<audio>`를 다시 쓴다. 이때는 앞의 무음을 건너뛰지 못한다.
- 바로 트는 소리 목록은 `DATA.소리.바로틀기`다. 지금은 외침 3개만 있다.

**시험한 것**
- 앞에 0.25초 무음을 붙인 시험용 소리로 1~3화를 자동 진행했다. 외침 24번이 모두 Web Audio로 났고, 그림과의 차이는 1ms 안쪽이었다. 0.25초 무음도 건너뛰었다.
- 웹 주소(http), 폴더째 열기(file://), HTML 한 파일(파일 안에 넣은 소리) 세 가지에서 모두 소리가 났다.
- 콘솔 오류는 없었고, 대본 비교(`node tools/check_script.mjs --ep 1`~`3`)도 일치했다.
- 실제 소리는 Claude가 듣지 못한다. 선생님이 직접 들어 보고 확인한다.

**외침 소리 파일 이름** (게임은 이 이름으로 찾는다)

| 외침 | 파일 (`assets/audio/se/`) | HTML 안의 이름 (`window.EMBED_AUDIO`) |
|---|---|---|
| 잠깐! | `shout_holdit.mp3` | `se/shout_holdit` |
| 이의 있음! | `shout_objection.mp3` | `se/shout_objection` |
| 받아라! | `shout_takethat.mp3` | `se/shout_takethat` |

## 3. 남은 일: 외침 소리 3개 옮기기

### 선생님께 받을 것
1. **예전 게임 1 HTML**: 다른 세션이 외침 소리를 넣은 파일. 소리가 이 파일 안에만 있다.
2. (저장소를 받을 수 없으면) **새 게임 1 HTML** `기억의_법정_게임1.html`: 2장의 고침이 들어 있고 소리는 없는 파일 (29.7MB, 11월 1일 만듦)

### ① 예전 HTML에서 소리 꺼내기

```
node tools/extract_audio.mjs 예전_게임1.html 꺼낸소리
```

- 들어 있는 소리 목록이 먼저 나오고, `꺼낸소리/se/…mp3`처럼 저장된다.
- **이름이 2장 표와 다르면** 표의 이름으로 바꾼다. 예: `objection.mp3` → `shout_objection.mp3`
- `EMBED_AUDIO`가 없다고 나오면, 그 세션이 다른 방식으로 넣은 것이다. HTML에서 `data:audio`를 찾아 직접 꺼낸다.
- 외침 3개만 쓴다. 나머지(다른 효과음, BGM)는 폴더에서 지운다. BGM이 있으면 옮길지 선생님께 여쭌다.

### ② 새 HTML에 넣기 (둘 중 하나)

**가. 저장소를 받았을 때 (권장)**
```
cp 꺼낸소리/se/shout_*.mp3 assets/audio/se/
node tools/build_single_html.mjs --game 1
```
- `dist/기억의_법정_게임1.html`에 외침 3개가 들어간다. 30MB를 넘으면 도구가 인물·배경 그림을 조금 낮은 품질로 저절로 다시 압축한다.

**나. 저장소 없이 HTML 파일만 있을 때**
```
node embed_audio.mjs 기억의_법정_게임1.html 꺼낸소리 기억의_법정_게임1_외침.html
```
- `embed_audio.mjs`는 폴더에 있는 소리를 **모두** 넣는다. 외침 3개만 남긴 폴더로 돌린다.
- 이 방법은 그림을 다시 압축하지 않는다. 새 HTML이 이미 29.7MB이니, 결과가 30MB를 넘으면 외침 파일을 줄이거나(모노 64~96kbps, 1초 안팎) 가 방법을 쓴다.

### ③ (골라서) 앞의 무음 자르기
- HTML 한 파일과 웹 주소에서는 게임이 앞의 무음을 저절로 건너뛰므로 꼭 하지 않아도 된다.
- 폴더째 열기(방법 3)도 쓸 거라면 잘라 둔다.
```
ffmpeg -i in.mp3 -af silenceremove=start_periods=1:start_threshold=-40dB -c:a libmp3lame -q:a 4 out.mp3
```

### ④ 확인
- 크롬으로 HTML을 열고 [처음부터] → 1화 증언 1에서 "잠깐!"을 들어 본다.
- 자동 확인 (Playwright): HTML을 열고 화면을 한 번 클릭(`page.mouse.click`)한 뒤 아래를 실행한다. 셋 다 `AudioBufferSourceNode`가 나오면 바로 트는 방식으로 난 것이다.
```js
const out = {};
for (const n of ['외침 "잠깐!"', '외침 "이의 있음!"', '외침 "받아라!"']) {
  G.audio.playing.clear(); await G.audio.se(n);
  const a = [...G.audio.playing][0]; out[n] = a ? a.constructor.name : '소리 없음';
}
out
```

### ⑤ 돌려줄 것
| 돌려줄 것 | 왜 |
|---|---|
| 외침을 넣은 게임 1 HTML | 수업에 바로 쓴다 |
| 외침 mp3 3개 (2장 표의 이름) | 저장소 `assets/audio/se/`에 올려 두어야 다음에 HTML을 다시 만들어도 소리가 빠지지 않는다. 다른 계정은 저장소에 올릴 권한이 없을 수 있으니, 선생님이 GitHub 웹에서 `claude/bold-turing-nt4dxk` 브랜치를 골라 올린다 |
| 소리 출처 (알면) | 저작권 확인용. 역전재판 원작 음성은 쓰지 않는다 (기획서 8장) |
