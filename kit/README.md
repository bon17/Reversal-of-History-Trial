# 법정 추리 수업 게임 키트

**선생님이 자기 수업 내용으로 법정 추리 웹 게임을 만드는 키트입니다.**
코딩을 몰라도 됩니다. 평소 쓰는 AI(Claude, ChatGPT, Gemini 등)에 수업 설계를 넣으면 게임이 만들어집니다.

중학교 역사 수업용 게임 「기억의 법정」의 엔진을 누구나 쓸 수 있게 다듬은 것입니다.

## 두 가지 판

| | [범용판 `general/`](general/) | [역사판 `history/`](history/) |
|---|---|---|
| 누구에게 | 모든 교과 | 역사 수업 |
| 게임의 뼈대 | 오개념을 교과 지식으로 뒤집기 | 통념과 왜곡을 **사료**로 뒤집기 |
| 예시 게임 | 「시든 화분 사건」 (과학) | 「지도를 불태운 나라?」 (김정호 옥사 이야기) |
| 더 들어 있는 것 | | 사료 비판 틀, 기억·책임 틀(🟥🟦🟩), 역사 수업의 원칙, 연표, 출처·실제 인물 점검 |

엔진과 만들기 도우미는 두 판이 같습니다. AI에게 주는 지침, 수업 설계서, 예시 게임, 안내 문서가 다릅니다.

## 시작하기

1. 이 저장소를 ZIP으로 받아 압축을 풉니다 (초록색 **Code** 버튼 → **Download ZIP**).
2. `kit/general/` 또는 `kit/history/` 폴더를 엽니다. 폴더 하나가 키트 하나입니다. 다른 곳으로 옮겨도 됩니다.
3. **`index.html`** 을 두 번 눌러 예시 게임을 해 봅니다.
4. **`maker.html`** 을 두 번 눌러 만들기 도우미를 엽니다. 화면의 ①~⑤를 따라갑니다.

설치할 것도, 인터넷도 필요 없습니다. 자세한 안내는 각 판의 `README.md` 와 `docs/처음_시작하기.md` 에 있습니다.

## 만드는 흐름

```
① 수업 설계 적기 ──→ ② 내 AI에게 붙여 넣기 ──→ ③ AI의 답을 넣고 점검
                                                   │  (문제가 있으면 버튼 하나로 AI에게 다시)
                                                   ↓
                    ⑤ 게임 파일 하나로 받기 ←── ④ 그림 넣기 (없어도 됨)
```

## 키트를 고치는 사람에게

- 엔진, 만들기 도우미, 공통 문서는 `general/` 이 원본입니다. 고친 뒤 `node kit/tools/sync.mjs` 를 실행하면 `history/` 에 복사되고 두 판의 묶음 파일이 다시 만들어집니다.
- 시험: `node kit/tools/test.cjs` (Node.js와 Playwright가 있을 때)
