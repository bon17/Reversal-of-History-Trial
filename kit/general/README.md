# 법정 추리 수업 게임 키트 · 범용판

**내 수업 내용으로 법정 추리 웹 게임을 만드는 키트입니다.** 코딩을 몰라도, 평소 쓰는 AI(Claude, ChatGPT, Gemini 등)만 있으면 됩니다.

학생은 누명을 쓴 사람을 변호하는 주인공이 되어, 증거를 모으고 증언의 모순을 찾아 반박합니다.
이때 **상대편의 주장은 학생들이 흔히 갖는 오개념**이고, **증거는 이 단원의 교과 지식**입니다. 게임을 끝내려면 배운 것으로 설명해야 합니다.

> 역사 수업에 쓴다면 [역사판](../history/)이 더 잘 맞습니다. 사료 비판, 출처 표기, 역사 수업의 원칙이 들어 있습니다.

## 3분 만에 맛보기

1. 이 폴더를 통째로 내 컴퓨터에 받습니다.
2. **`index.html`** 을 두 번 누릅니다 → 예시 게임 「시든 화분 사건」(중학교 과학, 약 10분)이 열립니다.
3. **`maker.html`** 을 두 번 누릅니다 → 만들기 도우미가 열립니다.

설치할 것도, 인터넷도 필요 없습니다.

## 내 게임 만드는 순서

| | 하는 일 | 걸리는 시간 |
|---|---|---|
| ① | 만들기 도우미에 **수업 설계**를 적는다 (단원, 학습 목표, 핵심 지식, 학생들의 오개념) | 10분 |
| ② | 만들어진 글을 **내 AI에게 붙여 넣는다.** AI가 사건을 설계하고 게임 데이터를 써 준다 | 10~20분 |
| ③ | AI의 답을 붙여 넣고 **[점검하기]**. 문제가 있으면 버튼 하나로 AI에게 고쳐 달라고 한다 | 5~10분 |
| ④ | (선택) 그림을 넣는다. 없어도 이모지 인물과 색 배경으로 나온다 | |
| ⑤ | 직접 해 보고, **게임 파일 하나(.html)** 로 받아 학생에게 나눠 준다 | 10분 |

자세한 안내는 [docs/처음_시작하기.md](docs/처음_시작하기.md)에 있습니다.

## 이 키트가 해 주는 것

- **그림이 없어도 되는 게임 엔진.** 대화, 조사, 증언과 반대 심문, 반격, 판결, 이어하기. 컴퓨터, 태블릿, 휴대폰에서 됩니다.
- **AI에게 줄 지침.** 수업에 맞는 사건을 설계하는 법과 데이터 쓰는 규칙이 들어 있어, AI가 게임을 바로 만들 수 있습니다.
- **점검 도구.** AI가 틀리게 쓴 곳(없는 증거, 풀 수 없는 문제, 틀린 이름)을 쉬운 말로 알려 주고, 끝까지 자동으로 실행해 봅니다.
- **사실 확인 목록.** AI가 쓴 교과 내용 가운데 선생님이 확인할 것을 따로 보여 줍니다.
- **쓰기 활동과 답 모으기.** 게임 끝에 학생이 생각을 쓰고, 답은 구글 시트에 모을 수 있습니다.
- **색 테마와 글자 바꾸기.** 화면 색, 버튼 글자, 증거 카드의 종류를 수업에 맞게 바꿉니다.

## 폴더 안내

| 파일·폴더 | 무엇인가 | 고치나요? |
|---|---|---|
| `index.html` | 게임. 두 번 누르면 열린다 | 아니요 |
| `maker.html` | 만들기 도우미 | 아니요 |
| `my-game/` | **내 게임의 내용** (설정, 이야기, 그림, 소리). 지금은 예시가 들어 있다 | **여기만 고친다** |
| `ai/` | AI에게 주는 지침, 데이터 형식, 수업 설계서 양식 | 필요하면 |
| `docs/` | 선생님용 안내 (시작하기, 그림, 나눠 주기, 답 모으기) | |
| `engine/` | 게임 엔진 | 아니요 |
| `tools/` | 점검·묶기 도구 (Node.js가 있을 때), 구글 시트 스크립트 | 아니요 |

## 꼭 지켜 주세요

- **AI가 쓴 내용은 선생님이 확인합니다.** AI는 그럴듯하게 틀린 내용을 쓸 때가 있습니다.
- **그림과 자료는 쓸 수 있는 것만 넣습니다.** ([docs/그림_넣기.md](docs/그림_넣기.md)의 저작권 안내)
- **학생 정보는 꼭 필요한 만큼만 모읍니다.** ([docs/답_모으기_구글시트.md](docs/답_모으기_구글시트.md))
