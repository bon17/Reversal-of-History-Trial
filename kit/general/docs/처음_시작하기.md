# 처음 시작하기

코딩을 몰라도 됩니다. **내가 평소 쓰는 AI**(Claude, ChatGPT, Gemini 등)와 이 키트만 있으면 됩니다.

## 0. 준비

1. 키트 폴더를 통째로 내 컴퓨터에 받습니다 (ZIP으로 받았다면 압축을 풉니다).
2. 폴더 안의 **`index.html`** 을 두 번 눌러 예시 게임을 5분만 해 봅니다. 어떤 게임인지 알아야 설계가 쉽습니다.

## 방법 1. 만들기 도우미로 만들기 (가장 쉬움)

폴더 안의 **`maker.html`** 을 두 번 눌러 엽니다. 화면의 ①~⑤를 차례로 따라가면 됩니다.

| 단계 | 하는 일 |
|---|---|
| ① 설계서 | 교과, 단원, 학습 목표, 핵심 지식, 학생들의 오개념을 적습니다. [예시로 채워 보기]를 눌러 보면 감이 옵니다. |
| ② AI에게 주기 | [AI에게 줄 글 만들기] → [복사하기] → 내 AI 대화창에 붙여 넣습니다. AI가 사건 설계안을 보여 주면 마음에 들 때까지 말로 고칩니다. "좋아, 데이터로 써 줘"라고 하면 게임 데이터를 써 줍니다. |
| ③ 답 넣고 점검 | AI가 써 준 데이터를 통째로 복사해 붙여 넣고 [점검하기]. 문제가 있으면 [AI에게 보낼 수정 요청 복사]를 눌러 AI에게 다시 붙여 넣습니다. 문제가 없어질 때까지 되풀이합니다. |
| ④ 그림 (선택) | 그림이 있으면 칸에 끌어다 놓습니다. 없어도 됩니다. |
| ⑤ 해 보기 · 내보내기 | [새 창에서 해 보기]로 직접 해 보고, [게임 파일 하나로 받기]로 받습니다. 받은 `.html` 파일이 내 게임입니다. |

**꼭 할 일:** ③에 나오는 「선생님이 확인할 사실」을 하나씩 확인하세요. AI는 그럴듯하게 틀린 내용을 쓸 때가 있습니다. 교과 내용의 책임은 선생님에게 있습니다.

## 방법 2. AI 대화창만으로 만들기

만들기 도우미를 쓰기 어려운 환경(태블릿 등)일 때.

1. AI 대화창에 `ai/AI_지침.md`, `ai/데이터_형식.md`, `my-game/story1.js`(예시) 파일을 첨부합니다.
2. `ai/수업_설계서.md` 를 열어 내용을 채운 뒤 붙여 넣고 "이 설계서로 게임 데이터를 만들어 줘"라고 합니다.
3. AI가 써 준 `DATA.게임` 은 `my-game/settings.js` 에, `DATA.ep1` 은 `my-game/story1.js` 에 붙여 넣어 저장합니다 (메모장으로 열어 전체를 바꿉니다).
4. `index.html` 을 엽니다. 데이터에 문제가 있으면 처음 화면에 **⚠ 데이터 점검** 버튼이 생깁니다. 눌러서 [AI에게 보낼 글 복사] → AI에게 붙여 넣기.

## 방법 3. 코딩 도구로 만들기 (Claude Code, Codex, Cursor 등)

이 폴더를 열고 이렇게 말하면 됩니다.

> 이 키트로 내 수업용 게임을 만들고 싶어. 필요한 걸 나한테 물어보고 만들어 줘.

도구가 `CLAUDE.md`(또는 `AGENTS.md`)를 읽고 설계를 물어본 뒤 `my-game/` 을 고치고 스스로 점검합니다.

## 만든 뒤에

- **고치기:** 받은 게임 파일(.html)을 만들기 도우미 ③의 [파일에서 불러오기]로 불러오면 이어서 고칠 수 있습니다. AI에게는 지금 데이터를 붙여 넣고 "여기서 ○○를 고쳐 줘. 전체 데이터를 다시 써 줘"라고 합니다.
- **장면 골라 보기:** 만들기 도우미의 [교사용으로 열기], 또는 주소 끝에 `?teacher` 를 붙이면 처음 화면에 [교사용: 장면 골라 시작]이 나옵니다.
- **학생에게 나눠 주기:** `docs/학생에게_나눠주기.md`
- **학생 답 모으기:** `docs/답_모으기_구글시트.md`
- **그림 넣기:** `docs/그림_넣기.md`

## 자주 묻는 것

**AI의 답이 중간에 끊겨요.** "끊긴 곳부터 이어서 써 줘"라고 하고, 이어진 글을 앞의 글 뒤에 붙여서 점검에 넣으세요. 자꾸 끊기면 "DATA.게임 먼저, 그다음 DATA.ep1 을 따로 써 줘"라고 하세요.

**점검에서 같은 오류가 계속 나와요.** 대화가 길어지면 AI가 앞의 내용을 잊습니다. 새 대화를 열고, ②의 글과 지금 데이터, 오류 목록을 함께 주세요.

**게임이 너무 길어요 / 짧아요.** "대사를 100줄 안으로 줄여 줘", "증언을 하나 더 넣어 줘"처럼 숫자로 말하면 잘 듣습니다.

**학생 기기에서 열리나요?** 크롬, 엣지, 사파리, 웨일 등 요즘 브라우저면 됩니다. 태블릿과 휴대폰에서는 세로 화면에 맞춰 바뀝니다.
