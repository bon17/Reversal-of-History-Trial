# 법정 추리 수업 게임 키트 · 역사판

**내 역사 수업 내용으로 법정 추리 웹 게임을 만드는 키트입니다.** 코딩을 몰라도, 평소 쓰는 AI(Claude, ChatGPT, Gemini 등)만 있으면 됩니다.

학생은 **사료를 모아 증언의 모순을 찾고**, 널리 퍼진 통념이나 왜곡된 주장을 **사료를 들어 반박**합니다.
"책에 나왔으니까 사실이지", "인터넷에서 봤는데"라는 말에 **누가, 언제, 왜 남긴 기록인가**를 되묻는 경험을 게임으로 하게 됩니다.

이 판은 중학교 역사 수업용 게임 「기억의 법정」(일제의 강제 동원과 홀로코스트를 다룬 6화짜리 법정 추리 게임)을 만들고 수업하면서 다듬은 원칙을 담았습니다.

## 범용판과 무엇이 다른가요

| | 범용판 | **역사판** |
|---|---|---|
| 증거 | 관찰 기록, 교과 지식 | **사료** (누가·언제 남겼는지, 출처가 함께 보인다) |
| 상대편의 주장 | 오개념 | **통념, 왜곡된 주장** |
| 증거 카드의 틀 | 자유 | **사료 비판 틀** (당시의 자료 / 후대의 글 / 연구 결과) 또는 **기억·책임 틀** (🟥 피해 기록 / 🟦 책임 기록 / 🟩 선택 기록) |
| AI 지침 | 공통 | 공통 + **역사 수업용 원칙** (실제 인물의 대사를 지어내지 않기, 피해자를 다루는 원칙, 사실과 해석 나누기 …) |
| 점검 | 공통 | 공통 + **출처 없는 사료, 실제 인물의 대사** 알림 |
| 꼭 넣는 장면 | 정리 카드, 쓰기 | **연표, 실제 역사 기록 카드, 잘못된 주장에 사료로 답장하기** |
| 예시 게임 | 「시든 화분 사건」 (과학, 그림 없음) | **원작 「기억의 법정」 제1화 「군함도의 명부」** (그림 포함, 약 40분) + 짧은 예시 「지도를 불태운 나라?」 (그림 없음, 약 10분) |

## 3분 만에 맛보기

1. 이 폴더를 통째로 내 컴퓨터에 받습니다.
2. **`index.html`** 을 두 번 누릅니다 → 예시 게임 「기억의 법정」 제1화 「군함도의 명부」(약 40분)가 열립니다.
   그림 없이 만든 10분짜리 예시는 **`example-daedong-map.html`** 로 엽니다.
3. **`maker.html`** 을 두 번 누릅니다 → 만들기 도우미가 열립니다.

설치할 것도, 인터넷도 필요 없습니다.

## 내 게임 만드는 순서

| | 하는 일 |
|---|---|
| ① | 만들기 도우미에 **수업 설계**를 적는다: 단원, 핵심 메시지, **학생들의 통념**, **쓸 사료 목록(출처와 함께)**, 지킬 원칙 |
| ② | 만들어진 글을 **내 AI에게 붙여 넣는다.** AI가 사건을 설계하고 게임 데이터를 써 준다 |
| ③ | AI의 답을 붙여 넣고 **[점검하기]**. 「선생님이 확인할 사실」 목록을 **하나씩 사료와 맞춰 본다** |
| ④ | (선택) 그림과 사료 사진을 넣는다. 쓸 수 있는 것인지 확인한다 |
| ⑤ | 직접 해 보고, **게임 파일 하나(.html)** 로 받아 학생에게 나눠 준다 |

- 처음이라면 [docs/처음_시작하기.md](docs/처음_시작하기.md)
- 역사 수업에 맞게 설계하려면 **[docs/역사_수업_도움말.md](docs/역사_수업_도움말.md)** (꼭 읽어 주세요)

## 예시 게임 두 편

**「기억의 법정」 제1화 「군함도의 명부」** (`my-game/`, 기본 예시)
이 키트의 바탕이 된 원작 게임의 제1화입니다. 1944년 하시마(군함도) 탄광에서 사고의 누명을 쓴 열일곱 살 광부를 변호합니다.
한 차시 분량의 완성된 역사 게임이 어떻게 짜여 있는지(누명을 벗기는 방식, 기억·책임 틀, 증언 여섯 개, 실제 역사 기록 카드, 기억 노트) 볼 수 있고, 그림을 넣은 게임의 설정도 볼 수 있습니다. 고쳐서 내 수업에 써도 됩니다.

**「지도를 불태운 나라?」** (`examples/daedong-map/`, 짧은 예시)
"김정호는 옥에 갇히고 목판은 불태워졌다"는 이야기를 사료로 따져 보는 10분짜리 게임입니다. 그림 없이 만들었고, 사료 비판 틀을 씁니다.
처음 만드는 게임은 이 정도 크기를 권합니다. 만들기 도우미가 AI에게 주는 글에는 이 예시가 형식 예시로 들어갑니다. ([examples/README.md](examples/README.md))

## 폴더 안내

| 파일·폴더 | 무엇인가 | 고치나요? |
|---|---|---|
| `index.html` | 게임. 두 번 누르면 열린다 | 아니요 |
| `maker.html` | 만들기 도우미 | 아니요 |
| `my-game/` | **내 게임의 내용** (설정, 이야기, 그림, 소리). 지금은 원작 제1화가 들어 있다 | **여기만 고친다** |
| `ai/` | AI에게 주는 지침(역사 수업용 원칙 포함), 데이터 형식, 수업 설계서 양식 | 필요하면 |
| `docs/` | 선생님용 안내 | |
| `examples/` | 짧은 예시 「지도를 불태운 나라?」 | 읽고, 복사해서 고쳐 쓴다 |
| `engine/`, `tools/` | 게임 엔진과 도구 | 아니요 |

## 꼭 지켜 주세요

- **AI가 쓴 역사 내용은 반드시 선생님이 사료와 맞춰 확인합니다.** AI는 연도, 이름, 인용문을 그럴듯하게 지어낼 때가 있습니다. 확인하지 않은 게임을 학생에게 주지 마세요.
- **실제 인물의 말과 행동을 지어내지 않습니다.** 이야기는 가상 인물이 끌고, 실제 인물은 실제 기록으로만 보여 줍니다.
- **사료와 사진은 쓸 수 있는 것만 넣고, 출처를 적습니다.**
- 전쟁, 식민 지배, 학살, 인권 침해를 다룰 때는 [docs/역사_수업_도움말.md](docs/역사_수업_도움말.md)의 「넘지 않는 선」을 먼저 읽어 주세요.
