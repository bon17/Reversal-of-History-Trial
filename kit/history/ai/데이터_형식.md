# 데이터 형식 (게임 데이터를 쓰는 규칙)

게임은 **두 덩어리의 데이터**로 이루어진다. 엔진(`engine/`)은 고치지 않는다.

| 덩어리 | 파일 | 내용 |
|---|---|---|
| `DATA.게임` | `my-game/settings.js` | 제목, 테마, 인물, 배경, 기록 종류, 소리 |
| `DATA.ep1`, `DATA.ep2` … | `my-game/story1.js`, `story2.js` … | 화마다 증거와 이야기 |

글자 규칙은 자바스크립트 객체 글자 그대로다.

- 글은 따옴표로 감싼다: `'안녕'`. 글 안에 `'` 가 있으면 바깥을 `"` 로 감싼다: `"그건 '거짓'이야"`.
- 묶음은 `{ 이름: 값, 이름: 값 }`, 목록은 `[ 값, 값 ]`. 항목 사이에 쉼표를 넣는다 (마지막 쉼표는 있어도 된다).
- `//` 뒤는 주석이다.
- 함수, 변수, 계산식은 쓰지 않는다. 데이터만 쓴다.

## 1. 설정: `DATA.게임`

```js
window.DATA = window.DATA || {};
DATA.게임 = {
  제목: '시든 화분 사건',
  부제: '과학 법정 추리',          // 없어도 된다
  만든이: '○○중학교 과학 ○○○',     // 없어도 된다
  아이디: 'wilted-pot',            // 저장 구분용. 영어 소문자, 숫자, - 만
  테마: '칠판',                    // '남색금빛' | '칠판' | '노을' | '바다' | '먹빛' | '숲'
                                   // 또는 { 바탕: '#1d4536', 포인트: '#f0e2a8', 글꼴: '고딕' } (글꼴: '고딕' | '명조')
  자리그림: '이모지',               // 그림이 없을 때 인물 모습. '이모지'(표정 이모지) | '실루엣'(차분한 그림자. 무거운 주제에)
  외침: { 추궁: '잠깐만요!', 제시: '반박합니다!' },
  버튼: { 추궁: '더 묻기', 제시: '증거 제시', 기록: '사건 기록' },
  신뢰도: { 칸: 5, 이름: '신뢰도' },
  주인공: '지우',                  // 학생이 맡는 인물
  조수: '소라',                    // 힌트를 주는 인물

  기록종류: {                      // 증거 카드의 색마다 이름과 성격
    파랑: { 이름: '관찰 기록', 표시: '🟦' },
    초록: { 이름: '과학 지식', 표시: '🟩', 제시연출: '빛' },
    개념: { 이름: '낱말 카드' },    // 읽기만 하는 카드 (제시할 수 없다)
  },

  인물: {
    '지우': { 자리: '변호인석', 화면밖: true, 이모지: '🛡️', 색: '#3f7fbf' },
    '소라': { 자리: '변호인석', 이모지: '📒', 색: '#e08a4a' },
    '한결': { 자리: '검사석', 이모지: '🔎', 색: '#8a4a6a' },
    '문 선생님': { 자리: '재판장석', 이모지: '🔬', 색: '#5a5a7a' },
    '하늘': { 자리: '피고석', 이모지: '💧', 색: '#4aa3c7' },
    '도윤': { 자리: '증언대', 이모지: '🧹', 색: '#6a9a4a' },
  },

  배경: {
    '과학실': { 이모지: '🔬', 색: ['#3d6b5a', '#12241d'] },
    '모의 법정': { 법정: true },
  },

  소리: { BGM: { '재판 음악': 'bgm/trial' }, 효과음: {} },
  저장주소: '',                    // 쓰기 활동 답을 모을 구글 시트 웹 앱 주소. 비워 둔다 (선생님이 넣는다)
  학생정보: ['반', '번호', '이름'],  // 쓰기 활동에서 물어볼 것. [] 이면 묻지 않는다
  화선택: '자유',                  // 화가 여러 개일 때. '자유' | '순서'(앞 화를 끝내야 열림) | '코드'(화의 코드를 넣어 시작)
};
```

### 기록종류 (증거의 색)

- 쓸 수 있는 색: `파랑`, `빨강`, `초록`, `노랑`, `보라`, `개념`. 쓸 것만 적는다. 증거의 `색` 에 이 이름을 쓴다.
- `이름`: 그 색 카드의 이름. 수업에 맞게 정한다 (예: 관찰 기록, 과학 지식, 본문 근거, 통계 자료).
- `표시`: 🟥🟦🟩🟨🟪 가운데 그 색. 대사 안에 이 이모지를 쓰면 작은 색 네모로 보인다.
- `오답벌칙없음: true`: 잘못 제시해도 신뢰도가 줄지 않는다 (조심히 다뤄야 하는 기록에).
- `제시연출`: `'차분'`(음악이 멈추고 화면이 차분해진다) 또는 `'빛'`(화면에 빛이 번진다).
- `개념` 은 **읽기만 하는 카드**다. 낱말 풀이에 쓴다. 정답 증거로 쓸 수 없다.

### 인물

- `자리`: `'변호인석'`(주인공 쪽), `'검사석'`(상대 쪽), `'증언대'`(증인), `'피고석'`, `'재판장석'`. 법정 장면에서 말하는 사람의 자리로 화면이 바뀐다.
- `화면밖: true`: 법정 밖에서는 화면에 서지 않고 대사창 옆 작은 얼굴로만 나온다. **주인공**에게 쓴다.
- `이모지`, `색`: 그림이 없을 때 쓰는 자리 그림의 가슴 표시와 옷 색.
- 그림을 쓸 때만: `파일: 'sora'` (영어 소문자), `얼굴: [512, 250, 180]` (얼굴의 가운데 x, y, 반지름. 그림 1024×1024 기준).
- `실존: true`: 실제 인물일 때 적는다. 점검 도구가 "지어낸 대사가 아닌지 확인하라"고 알려 준다.

### 표정

대사의 `표정` 에 쓸 수 있는 이름:
`기본`, `미소`, `놀람`, `생각`, `당황`, `진지`, `슬픔`, `분노`, `자신감`, `결의`, `걱정`, `안도`, `비웃음`, `겁먹음`, `엄숙`, `감사`, `난처함`, `미안함`, `무표정`, `지침`

### 배경

- `이모지`, `색: [위쪽 색, 아래쪽 색]`: 그림이 없을 때 쓰는 자리 그림.
- `법정: true`: 재판 장면의 배경. 하나만 만들면 된다. 자리별 그림은 엔진이 알아서 그린다.
- 그림을 쓸 때만: `그림: 'backgrounds/lab'`. 인물이 서는 곳을 그림에 맞추려면 `인물자리: [왼쪽, 위, 너비, 높이]` (장면에 대한 %, 예: `[17, 0, 66, 100]`).
- `'검은 화면'` 은 적지 않아도 쓸 수 있다.

## 2. 이야기: `DATA.ep1`

```js
window.DATA = window.DATA || {};
DATA.ep1 = {
  번호: 1,
  제목: '시든 화분 사건',
  증거: { … },          // 아래 2-1
  오답: { 일반: [ … ] }, // 틀린 증거를 냈을 때 함께 쓰는 대사 (없어도 된다)
  사실확인: [ '…' ],     // 이야기에 쓴 사실 가운데 선생님이 확인할 것 (교사용 화면에만 나온다)
  막: [                  // 아래 2-2
    { 이름: '사건 발생', 내용: [ 명령, 명령, … ] },
    { 이름: '조사', 내용: [ … ] },
  ],
};
```

### 2-1. 증거

```js
증거: {
  pot_photo: {                       // 이름표: 영어 소문자, 숫자, _ 만. 명령에서 이 이름표로 부른다
    이름: '월요일 아침의 화분',
    색: '파랑',                      // 기록종류의 색
    아이콘: '🪴',                    // 그림이 없을 때 카드에 보이는 이모지
    비고: '과학 교과서',              // 없어도 된다. 이름 옆 작은 글
    설명: ['첫 문단', '**굵게** 보일 곳은 별 두 개로 감싼다'],
    출처: '○○박물관',                // 없어도 된다. 실제 사진, 사료, 통계에는 꼭 적는다
    정보: { 누가: '…', 언제: '…' },   // 없어도 된다. 기록 화면에 표로 보인다 (자료를 따져 볼 때)
    갱신: [ { 방식: '추가', 설명: ['새로 알게 된 내용'] } ],  // 없어도 된다. { 증거갱신 } 으로 차례로 적용
  },
},
```

- 설명은 학생이 **그 증거만 읽고도 무엇을 증명하는지 알 수 있게** 쓴다. 정답의 단서가 되는 낱말은 `**굵게**`.
- 그림을 쓸 때만: `그림: 'evidence/pot_photo'`. 인물 얼굴을 카드 그림으로 쓰려면 `얼굴: ['하늘', '슬픔']`.

### 2-2. 막과 명령

`막` 은 이야기의 큰 토막이다. `내용` 에 **명령을 차례로** 적는다. 명령 하나는 `{ 명령이름: 값, … }` 이다.

#### 자주 쓰는 명령

| 명령 | 뜻 |
|---|---|
| `{ 구간: '조사' }` | 이어하기 저장 지점. 장면이 크게 바뀌는 곳마다 넣는다 |
| `{ 배경: '과학실' }` | 배경을 바꾼다. 인물과 대사창이 치워진다 |
| `{ 말: '소라', 표정: '미소', 대사: '…' }` | 대사. `(괄호로 감싼 대사)` 는 속마음(하늘색). 인물 표에 없는 이름은 이름만 나온다 |
| `{ 증거획득: 'pot_photo' }` | 증거를 얻는다 (알림이 뜬다) |
| `{ 증거갱신: 'pot_photo' }` | 증거의 `갱신` 을 하나 적용한다 |
| `{ 선택지: [ { 글: '…', 정답: true }, { 글: '…', 결과: [ 명령… ] } ] }` | 정답을 고를 때까지 다시 묻는다. 오답에는 `결과` 를 넣는다. **정답 표시가 하나도 없으면** 무엇을 골라도 넘어가는 선택지(의견 고르기)가 된다 |
| `{ 안내창: ['첫 줄', '둘째 줄'], 제목: '조사하기' }` | 조작 설명 창 |
| `{ BGM: '재판 음악' }` `{ BGM: '멈춤' }` | 음악. 이름 뒤에 `(잔잔하게)`, `(낮게)`, `(크게)` 를 붙일 수 있다 |
| `{ 효과음: '망치 소리' }` | 효과음 |
| `{ 재판: '시작' }` `{ 재판: '끝' }` | 재판 장면의 시작과 끝. 시작하면 신뢰도 칸이 보인다 |

#### 연출 명령

| 명령 | 뜻 |
|---|---|
| `{ 등장: '도윤', 표정: '기본' }` | 인물이 천천히 나타난다 (대사 없이) |
| `{ 보이기: '하늘', 표정: '슬픔' }` | 인물을 바로 세운다 (대사 없이) |
| `{ 퇴장: '도윤' }` `{ 인물숨기기: true }` | 인물을 치운다 |
| `{ 이름표: ['도윤', '금요일 청소 당번'] }` | 처음 나오는 인물의 이름과 소개를 잠깐 띄운다 |
| `{ 외침: '제시' }` `{ 외침: '추궁' }` `{ 외침: '아무 글자!' }` | 큰 글자 외침. 정답 장면의 맨 앞에 쓴다 |
| `{ 띠: '최종 변론' }` | 장면 제목이 가운데를 지나간다 |
| `{ 증거제출: '$제시' }` | 방금 학생이 낸 증거 카드를 가운데에 띄운다. 정답 장면에서 쓴다. 이름표를 직접 적어도 된다 |
| `{ 증거보이기: ['a', 'b'] }` | 증거 카드 여러 장을 구석에 띄운다 (다음 대사까지) |
| `{ 자막: ['첫 줄', '둘째 줄'] }` | 검은 화면에 글. `크게: true`, `겹쳐: true`(장면을 비친 채), `길게: true` |
| `{ 종이: ['제목', '줄', '줄'], 제목줄: true }` | 종이 한 장에 글이 한 줄씩 (편지, 일기, 보고서) |
| `{ 인용: '실제 기록의 문장', 이름: '기록 이름', 출처: '…' }` | 실제 기록이나 증언을 **그대로** 옮길 때. 지어낸 대사와 구분되어 보인다 |
| `{ 사진: 'pot_photo' }` `{ 사진: null }` | 증거의 그림을 화면 가득 (출처가 함께 보인다) |
| `{ 컷: 'backgrounds/cut1' }` `{ 컷: null }` | 장면 위에 그림 한 장 (그림 파일이 있을 때) |
| `{ 연출: '흔들림' }` | `흔들림`, `크게 흔들림`, `반짝`, `암전`, `암전 끝`, `휘청`, `정적`, `차분하게`, `차분함 끝`, `빛`, `빛 끝`, `비`, `비 그침`, `회상`, `회상 끝`, `어둡게`, `밝게` |
| `{ 대기: 1000 }` | 1초 쉰다 |
| `{ 판결: '무죄' }` | 큰 글자 판결. 글자는 자유 (짧게: 2~5자) |
| `{ 기록카드: { 제목: '…', 문단: ['…', '…'], 출처: '…' } }` | 정리 카드 한 장 (실제 사실, 교과 지식 정리) |
| `{ 표: { 제목: '…', 머리: ['칸', '칸'], 줄: [['칸', '칸'], …] } }` | 표 화면 |
| `{ 연표: { 제목: '…', 줄: [['1861년', '일어난 일'], …], 강조: [2] } }` | 연표 화면. 강조: 눈에 띄게 할 줄 번호 |
| `{ 부제목: ['작은 줄', '큰 줄'] }` | 제목 화면 |
| `{ 다음화: '제2화 「…」' }` | 화가 끝난다 (다음 화 예고) |
| `{ 끝: ['마지막 인사'] }` | 게임이 끝난다 |

## 3. 조사 파트

장소를 골라 돋보기를 눌러 조사한다. 모든 장소의 모든 포인트를 조사해야 다음으로 넘어간다.

```js
{ 조사파트: {
  음악: '조사 음악',                 // 없어도 된다
  장소: [
    { 이름: '과학실 창가', 배경: '과학실 창가',
      도착: [ 명령… ],               // 처음 갔을 때 한 번 나오는 대화. 없으면 []
      포인트: [
        { 이름: '시든 화분', 위치: [560, 300, 420, 360], 내용: [ 명령… ] },
        { 이름: '창틀 뒤쪽', 위치: [1120, 200, 300, 300], 내용: [ 명령… ] },
      ] },
    { 이름: '과학 준비실', 배경: '과학 준비실',
      도착: [ 명령… ], 포인트: [] },  // 포인트가 없으면 이야기만 듣는 곳
  ],
  마무리: [ 명령… ],                 // 다 조사한 뒤 나오는 대화
} }
```

- `위치: [왼쪽 x, 위 y, 너비, 높이]`. 화면은 가로 1536, 세로 1024. 돋보기는 그 칸의 가운데에 뜬다.
  **세로(y + 높이/2)는 150~700 사이**에 두고, 포인트끼리 겹치지 않게 300 이상 떨어뜨린다.
- `열림: ['과학실 창가']`: 그 장소를 다 조사해야 갈 수 있는 장소에 적는다.
- 장소는 2~4곳, 장소마다 포인트 1~3개가 알맞다.
- **재판에서 정답이 되는 증거는 모두 재판 전에 얻게 한다.**

## 4. 증언과 반대 심문

증인이 증언하면 학생이 문장을 넘겨 보며 **[더 묻기]**(추궁)를 하고, 기록과 맞지 않는 문장에서 **[증거 제시]**를 한다.

```js
{ 증언: {
  제목: '월요일 아침에 본 것', 증인: '도윤', 표정: '기본',
  문장: [
    { 글: '월요일 아침에 제가 제일 먼저 과학실에 왔어요.', 추궁: [
      { 말: '지우', 표정: '기본', 대사: '몇 시쯤이었나요?' },
      { 말: '도윤', 표정: '기본', 대사: '8시 10분쯤이요.' },
    ] },
    { 글: '화분의 잎이 축 늘어져 있었어요. 〔흙이 바싹 말라서〕 그런 거예요.', 추궁: [ … ] },
    { 글: '금요일 당번인 하늘이가 물 주는 걸 잊은 게 틀림없어요.', 추궁: [ … ] },
  ],
  정답: [{ 문장: 2, 증거: 'pot_photo' }],     // 2번 문장에서 pot_photo 를 내면 정답
  힌트: { 말: '소라', 표정: '생각', 대사: '…' }, // 두 번 틀리면 나온다
  정답장면: [
    { 외침: '제시' },
    { 증거제출: '$제시' },
    { 말: '지우', 표정: '자신감', 대사: '…이 증언은 사실과 맞지 않습니다!' },
    { 연출: '흔들림' },
    { 말: '도윤', 표정: '놀람', 대사: '…' },
  ],
} }
```

- **문장은 3~5개.** 정답 문장은 보통 하나. `문장` 번호는 1부터 센다.
- `〔 〕` 로 감싼 낱말은 주황색으로 보인다. 캐물을 만한 곳(정답 문장의 핵심 낱말)에 쓴다.
- **모든 문장에 `추궁` 을 넣는다.** 추궁은 벌칙이 없고, 정답의 실마리를 준다.
- `정답` 에 여러 개를 적으면 그중 아무거나 맞다: `[{ 문장: 2, 증거: 'a' }, { 문장: 3, 증거: 'a' }]`
- `일반오답: [ 명령… ]`: 이 증언에서 틀렸을 때의 대사. 적지 않으면 화의 `오답.일반` 을 쓴다.

#### 더 쓸 수 있는 것

```js
// 추궁하면 증언이 바뀌는 문장 → 바뀐 문장에 증거를 내야 정답
{ 글: '저는 아무것도 못 봤어요.', 추궁: [ … ],
  수정: { 글: '…사실은 창문 너머로 봤어요.', 뒤: [ 명령… ] } },
정답: [{ 문장: 2, 증거: 'a', 수정후: true }],

// 한 증언에서 정답을 차례로 여러 번 찾기 (정답, 힌트, 정답장면 대신 단계를 쓴다)
단계: [
  { 정답: [{ 문장: 2, 증거: 'a' }], 힌트: { … }, 정답장면: [ … ] },
  { 앞: [ 명령… ], 정답: [{ 문장: 3, 증거: 'b' }], 힌트: { … }, 정답장면: [ … ] },
],

// 틀린 것은 아니지만 결정적이지 않은 증거: 장면만 보여 주고 벌칙 없이 돌아간다
보조정답: [{ 문장: 3, 증거: 'c', 장면: [ 명령… ] }],

// 증거 없이, 그 문장을 추궁하기만 하면 넘어가는 증언
추궁정답: 2, 정답장면: [ … ],
```

## 5. 반격

상대의 주장 한 문장에 맞는 증거를 골라 반박한다 (증언 없이).

```js
{ 반격: { 단계: [
  { 앞: [ 명령… ],                                        // 주장 앞의 대화. 없어도 된다
    주장: { 말: '한결', 표정: '자신감', 대사: '물이 충분했다면 시들 까닭이 없어!' },
    질문: '화분에 다른 이상이 있었음을 보여 주는 기록은?',  // 학생에게 보이는 도움말
    정답: ['root_photo'],                                  // 여러 개면 아무거나 맞다
    힌트: { 말: '소라', 표정: '생각', 대사: '…' },
    정답장면: [ { 외침: '제시' }, { 증거제출: '$제시' }, 명령… ] },
  { 주장: { … }, 질문: '…', 정답: ['root_breath'], 힌트: { … }, 정답장면: [ … ] },
] } }
```

## 6. 쓰기 활동

게임이 끝난 뒤 학생이 생각을 고르고 쓴다. 답은 구글 시트로 모을 수 있다.

```js
{ 쓰기: {
  제목: '탐구 노트',
  안내: ['사건을 해결했어요!', '마지막으로 **탐구 노트**를 써 봅시다.'],
  문항: [
    { 종류: '증거', 이름: '결정적인 기록', 질문: '가장 결정적이었던 기록을 골라 주세요.' },
    { 종류: '고르기', 이름: '시든 원인', 질문: '…', 보기: ['…', '…', '…'], 풀이: '고른 뒤 보여 줄 설명' },
    { 종류: '인물', 이름: '…', 질문: '…', 인물: ['도윤', '하늘'] },
    { 종류: '한줄', 이름: '원인을 한 문장으로', 질문: '…', 도움말: '예: …', 최소: 10 },
    { 종류: '길게', 이름: '내 생각', 질문: '…', 최소: 20 },
    { 종류: '답장', 이름: '친구에게 답장', 보낸이: '친구', 메시지: '식물은 물만 많이 주면 잘 자라잖아.', 최소: 15 },
  ],
  끝인사: '수고했어요!',
} }
```

- `이름` 은 구글 시트의 열 이름이 된다. 짧게 쓴다.
- `고르기` 에 `여러개: true` 를 넣으면 여러 개 고를 수 있다. `풀이` 는 정답을 알려 줄 때만 넣는다 (의견을 묻는 문항에는 넣지 않는다).
- `답장`: 잘못된 주장(`메시지`)에 학생이 증거 하나를 골라 답장을 쓴다. 배운 것으로 스스로 반박해 보는 문항이다.
- `최소`: 띄어쓰기를 뺀 최소 글자 수.

## 7. 한 화의 뼈대

```js
막: [
  { 이름: '사건 발생', 내용: [
    { 구간: '사건 발생' }, { 배경: … }, 대화…,            // 피고가 잘못한 것처럼 보인다
    { 선택지: [ { 글: '변호를 맡는다', 정답: true }, … ] },
  ] },
  { 이름: '조사', 내용: [
    { 구간: '조사' }, { 안내창: [ … ] }, { 조사파트: { … } },  // 증거를 모은다
  ] },
  { 이름: '재판', 내용: [
    { 구간: '재판 시작' }, { 배경: '법정 배경' }, { 재판: '시작' }, 대화…,
    { 안내창: [ … ] }, { 증언: { … } },                    // 증언 1: 모순 찾기
    { 반격: { … } },                                       // 상대의 반론에 지식으로 답하기
    { 구간: '두 번째 증언' }, 대화…, { 증언: { … } },        // 증언 2: 진짜 원인이 드러난다
    { 구간: '최종 변론' }, { 띠: '최종 변론' }, 대화…, { 판결: '무죄' }, { 재판: '끝' },
  ] },
  { 이름: '마무리', 내용: [
    { 구간: '마무리' }, { 배경: … }, 대화…,
    { 기록카드: { … } },                                   // 배운 것 정리
    { 쓰기: { … } },                                       // 생각 쓰기
    { 끝: ['…'] },
  ] },
],
```

## 8. 꼭 지킬 것 (점검 도구가 확인한다)

1. 명령에 쓴 **증거 이름표**는 모두 `증거` 표에 있어야 한다.
2. 정답 증거는 그 증언이나 반격보다 **앞에서 `증거획득`** 으로 얻어야 한다. `개념` 카드는 정답이 될 수 없다.
3. `말` 의 이름은 `인물` 표의 이름과 **글자 하나까지 같아야** 한다.
4. `배경` 이름은 `배경` 표에, `표정` 은 표정 목록에 있어야 한다.
5. 증언마다 `정답`(또는 `단계`, `추궁정답`), `힌트`, `정답장면` 이 있어야 한다.
6. 재판 장면 앞에 `{ 재판: '시작' }` 이 있어야 신뢰도가 움직인다.
7. 화의 끝에는 `{ 끝: … }` 또는 `{ 다음화: … }` 를 둔다.
