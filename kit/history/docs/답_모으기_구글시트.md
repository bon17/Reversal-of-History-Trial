# 학생 답 모으기 (구글 시트)

쓰기 활동의 답을 구글 시트 한 곳에 모을 수 있습니다. 설정하지 않아도 게임은 됩니다. 그때는 학생 화면에 답이 나오고, [답 복사하기]나 [파일로 받기]로 내게 할 수 있습니다.

## 설치 (10분, 처음 한 번)

1. 구글 드라이브에서 **구글 시트를 새로 하나** 만듭니다. 이름은 자유입니다 (예: 시든 화분 사건 답).
2. 시트의 메뉴에서 **[확장 프로그램 → Apps Script]** 를 누릅니다.
3. 열린 화면의 글을 모두 지우고, 키트의 **`tools/gas/Code.gs`** 내용을 모두 붙여 넣습니다. 💾 저장.
4. 오른쪽 위 **[배포 → 새 배포]** → 톱니바퀴에서 **웹 앱** 을 고릅니다.
   - 실행 사용자: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - [배포] → 권한을 묻는 창이 나오면 내 계정으로 허용합니다.
5. 나온 **웹 앱 주소**(`https://script.google.com/macros/s/…/exec`)를 복사합니다.
6. 게임 설정의 `저장주소` 에 넣습니다.
   - 만들기 도우미를 쓴다면: ③의 글에서 `저장주소: ''` 를 찾아 따옴표 사이에 주소를 붙여 넣고 [점검하기] → ⑤에서 다시 받습니다.
   - 폴더로 쓴다면: `my-game/settings.js` 의 `저장주소: ''` 에 넣습니다.

## 확인

게임을 열어 쓰기 활동을 한 번 해 보고 [저장하기]를 누릅니다. 시트에 쓰기 활동의 제목으로 된 탭이 생기고 한 줄이 들어오면 성공입니다. 시험 줄은 지웁니다.

- 열 이름은 문항의 `이름` 입니다. 문항을 더하면 열이 뒤에 더해집니다.
- 같은 학생이 다시 쓰면 줄이 하나 더 생깁니다. 가장 아래 줄이 최신입니다.
- 스크립트를 고쳤다면 [배포 → 배포 관리 → ✏ → 버전: 새 버전 → 배포]를 해야 반영됩니다. 주소는 그대로입니다.

## 학생 정보 다루기

- 시트에는 학생의 반, 번호, 이름과 답이 쌓입니다. 시트의 공유 설정은 **'제한됨'** 으로 두고, 학기가 끝나면 지웁니다.
- 이름을 모으기 조심스러우면 설정의 `학생정보: ['반', '번호']` 로 바꿉니다. `[]` 로 두면 아무것도 묻지 않습니다.
- 웹 앱 주소를 아는 사람은 누구나 시트에 줄을 더할 수 있습니다 (읽을 수는 없습니다). 주소는 게임 파일 안에 들어 있으니, 이상한 줄이 들어오면 새로 배포해 주소를 바꾸세요.
- 학교의 개인정보 처리 방침에 맞는지 확인하고 쓰세요.
