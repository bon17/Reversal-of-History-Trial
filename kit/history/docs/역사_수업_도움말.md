# 역사 수업 도움말

역사 수업용 게임을 설계할 때 알아 두면 좋은 것을 모았습니다.
중학교 역사 수업용 게임 「기억의 법정」(일제의 강제 동원과 홀로코스트를 다룬 법정 추리 게임)을 만들고 수업하면서 다듬은 원칙입니다.
같은 내용이 AI 지침(`ai/AI_지침.md`)에도 들어 있어서, AI도 이 원칙에 따라 게임을 만듭니다.

## 1. 왜 법정 추리 게임인가

역사 왜곡은 대개 이렇게 작동합니다. **그럴듯한 정황 하나를 보여 주고, 나머지를 보지 못하게 합니다.**
법정 추리 게임은 이 과정을 거꾸로 겪게 합니다.

1. 처음에는 잘못된 주장이 **그럴듯하게** 들린다. 학생도 일단 믿는다.
2. 사료를 모으고 따져 묻다 보면 **맞지 않는 곳**이 보인다.
3. 학생이 **자기 손으로** 사료를 내밀어 뒤집는다.

교사가 "그건 사실이 아니야"라고 말해 주는 것과, 학생이 사료를 골라 반박해 보는 것은 다릅니다.
목표는 수업이 끝난 뒤 학생이 **왜곡된 말을 들었을 때 스스로 반박할 수 있게** 되는 것입니다.

## 2. 증거 카드의 틀 고르기

증거 카드를 어떤 종류로 나눌지가 수업의 뼈대입니다. 두 가지 틀을 준비했습니다.

### 사료 비판 틀: 통념을 뒤집는 수업

| 카드 | 뜻 | 예 |
|---|---|---|
| 🟦 당시의 자료 | 그 시대에 만들어진 것 | 유물, 당시의 문서, 그때 찍은 사진 |
| 🟪 후대의 글 | 나중에 쓰인 글 | 신문 글, 교과서, 전기, 영상 |
| 🟩 연구 결과 | 연구자들이 확인한 것 | 조사 보고, 학계의 정리 |

- 학생이 던지는 질문은 하나입니다. **"이건 누가, 언제, 왜 남긴 거지?"**
- 어울리는 주제: 널리 퍼진 일화의 사실 여부, 같은 사건을 다르게 적은 두 기록 견주기, 선전물 읽기, 교과서 서술의 변화.
- 예시 게임 「지도를 불태운 나라?」가 이 틀입니다.

### 기억·책임 틀: 전쟁, 식민 지배, 학살, 인권 침해를 다루는 수업

| 카드 | 증명하는 것 | 예 |
|---|---|---|
| 🟥 피해 기록 | 이런 일이 있었고, 사람들이 고통받았다 | 증언, 사진, 지도, 통계, 유품, 일기 |
| 🟦 책임 기록 | 누가 명령하고 실행했는가 | 명령서, 법령, 연설, 정책 문서, 서명 |
| 🟩 선택 기록 | 같은 상황에서도 다른 선택이 가능했다 | 명령을 거부한 사람, 피해자를 도운 사람의 기록 |

이 틀은 메시지를 **세 계단**으로 쌓습니다.

1. 이런 일이 있었고, 수많은 사람이 고통받았다.
2. 누가 명령하고 실행했는지는 기록으로 분명하다.
3. "그때는 어쩔 수 없었다"며 따른 사람들에게도 책임이 있다. 다른 선택을 한 사람이 있었기 때문이다.

**3단계는 반드시 2단계를 확실히 끝낸 뒤에 다룹니다.** 책임을 나누는 것이 아니라 **더하는** 것입니다.
순서가 바뀌면 "명령한 사람만 나쁜 건 아니네 → 그럼 덜 나쁘네"로 읽힐 수 있습니다.

게임에서 이 틀의 카드는 다르게 움직입니다.

- 🟥 피해 기록은 **잘못 제시해도 벌칙이 없습니다.** 제시하면 음악이 멈추고 화면이 차분해집니다.
- 🟩 선택 기록을 제시하면 화면에 빛이 번집니다.
- 🟩 선택 기록에는 **가해국 사람도** 넣습니다. 나라가 아니라 선택의 문제임을 보여 줍니다.

설정에는 이렇게 적습니다 (AI에게 "기억·책임 틀로 해 줘"라고 하면 됩니다).

```js
기록종류: {
  빨강: { 이름: '피해 기록', 표시: '🟥', 오답벌칙없음: true, 제시연출: '차분' },
  파랑: { 이름: '책임 기록', 표시: '🟦' },
  초록: { 이름: '선택 기록', 표시: '🟩', 제시연출: '빛' },
  개념: { 이름: '개념 카드' },
},
자리그림: '실루엣',   // 이모지 얼굴 대신 차분한 그림자로
```

## 3. 이야기의 두 가지 방식

**이야기를 재판한다.** 지금의 학교에서 모의재판을 엽니다. 재판받는 것은 사람이 아니라 "널리 퍼진 이야기"입니다. 실제 인물은 등장하지 않고 사료로만 다룹니다. **처음 만드는 분께 권합니다.**

**누명을 벗긴다.** 그 시대를 무대로, 누명을 쓴 **가상의 인물**을 변호합니다. 「기억의 법정」이 이 방식입니다.

- 처음에는 피고가 정말 잘못한 것처럼 보입니다. 변호하면서 그게 아니었음이 드러납니다.
- 진범은 법정에 증인으로 나온 사람입니다. 처음에는 친절하고 점잖습니다. **악은 괴물의 얼굴을 하고 있지 않다**는 것을 학생이 겪게 됩니다.
- 진범의 변명("어쩔 수 없었다")은 그 장면에서 사료로 반박됩니다.
- 판결 뒤에 **「실제 역사 기록」** 카드로 현실은 어땠는지 보여 줍니다. 게임에서는 이겼지만 실제로는 아무도 벌받지 않았다면, 그대로 씁니다.

## 4. 넘지 않는 선

| 원칙 | 까닭 |
|---|---|
| **실제 인물의 대사와 행동을 지어내지 않는다.** 실제 기록만 인용한다 | 게임 속 대사를 학생은 사실로 기억합니다 |
| **실제 피해자를 피고로 세우지 않는다.** 피해자의 증언을 의심하게 만들지 않는다 | 불리한 정황은 서류나 가해자 쪽 주장에서 나오게 합니다 |
| **참혹한 장면을 그리거나 자세히 묘사하지 않는다** | 지도, 문서, 유품, 통계 같은 교과서 수준의 자료로 충분합니다 |
| **왜곡된 주장은 그 장면 안에서 반드시 반박한다** | 반박되지 않은 왜곡은 학생에게 남습니다 |
| **혐오 표현, 인터넷 밈, 가해 집단의 상징을 그대로 쓰지 않는다** | 게임이 그것을 퍼뜨리는 통로가 되면 안 됩니다 |
| **특정 나라나 민족 전체를 탓하지 않는다** | 잘못은 침략과 차별의 제도, 그것을 따른 선택에 있습니다 |
| **사실, 해석, 평가를 나누어 말한다** | "연구자들은 …라고 본다"처럼 씁니다 |
| **모르는 것은 모른다고 쓴다** | 기록의 빈자리를 지어내 채우지 않습니다 |
| **무거운 주제를 오락처럼 쓰지 않는다** | 피해자의 이야기는 선택지 없이 끝까지 듣는 장면으로 만듭니다 |

## 5. AI가 쓴 역사 내용 확인하기

AI는 연도, 이름, 숫자, 인용문을 **그럴듯하게 지어낼 때가 있습니다.** 역사 게임에서는 치명적입니다.

1. **사료 목록은 선생님이 줍니다.** 설계서의 「쓸 사료 목록」에 출처와 함께 적어 주세요. AI에게 사료를 찾아 달라고 하지 마세요.
2. 만들기 도우미 ③의 **「선생님이 확인할 사실」** 을 하나씩 교과서, 사료 원문과 맞춰 봅니다.
3. 게임의 **모든 대사를 한 번은 직접 읽습니다.** 설정 화면의 [지난 대사 보기]나, `?teacher` 로 열어 장면을 골라 보면 편합니다.
4. 점검이 **실제 인물의 대사**를 알려 주면, 실제 기록에 있는 말인지 확인합니다. 지어낸 말이면 가상 인물에게 맡기거나 `인용` 으로 바꿔 달라고 합니다.
5. 틀린 곳을 찾으면 AI에게 "○○는 사실이 아니야. △△로 고치고 전체 데이터를 다시 써 줘"라고 합니다.

## 6. 사료와 사진을 쓸 때

- **출처를 적습니다.** 증거에 `출처` 를 적으면 게임 안에 함께 나옵니다. 누가, 언제 남겼는지는 `정보` 에 적습니다.
- **쓸 수 있는 자료인지 확인합니다.** 수업 시간에 교실에서 보여 주는 것과, 게임 파일에 넣어 나눠 주거나 누리집에 올리는 것은 기준이 다릅니다.
  - 공공 기관(박물관, 기록원, 편찬 기관)의 자료는 자료마다 이용 조건이 붙어 있습니다. 공공누리 표시가 있으면 **유형을 확인**합니다 (출처 표시, 상업적 이용, 변경 가능 여부가 유형마다 다릅니다).
  - 교과서와 부교재의 사진, 지도, 삽화는 출판사와 원저작자에게 권리가 있습니다. 게임에 그대로 넣어 누리집에 올리지 않습니다. 필요하면 "교과서 ○○쪽을 함께 펴 보세요"라고 안내하는 방법이 있습니다.
  - 오래된 사진이라도 소장 기관이 이용 조건을 정해 둔 경우가 있습니다.
  - 확실하지 않으면 사진을 넣지 말고, 사료의 내용을 글로 옮기고 출처를 적습니다. 이 키트는 그림 없이도 됩니다.
- **사료의 문장을 고치지 않습니다.** 줄였으면 "(요약)", 요즘 말로 풀었으면 "(풀어 씀)"이라고 적습니다.
- **가상의 자료는 가상이라고 적습니다.** 이야기를 위해 만든 편지, 책, 인물은 `비고: '이야기 속 가상의 자료'` 로 구분하고, 수업에서도 알려 줍니다.

## 7. 수업 운영

- **2인 1조.** 한 명이 조작하고 한 명이 사료를 읽습니다. "이게 모순 아니야?"라는 대화가 수업의 핵심입니다.
- **쓰기 활동 10분은 꼭 남깁니다.** 「잘못된 주장에 답장하기」는 한 사람씩 씁니다.
- 수업 전에 같은 질문("○○는 어쩔 수 없었을까?")을 묻고, 게임 뒤에 다시 물으면 **생각이 어떻게 바뀌었는지** 볼 수 있습니다.
- 끝난 뒤 함께 이야기합니다. "처음에는 왜 그 이야기를 믿었나요?", "어떤 사료가 생각을 바꾸었나요?"
- 무거운 주제에서는 수업 전에 다룰 내용을 미리 알리고, 힘들어하는 학생이 쉴 수 있게 합니다.
