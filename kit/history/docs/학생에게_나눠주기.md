# 학생에게 나눠 주기

## 방법 1. 게임 파일 하나를 나눠 주기 (가장 쉬움)

만들기 도우미 ⑤의 [게임 파일 하나로 받기]로 받은 `.html` 파일을 학급 게시판, 메신저, 클래스룸에 올립니다. 학생은 파일을 받아 열면 됩니다. 인터넷이 없어도 됩니다.

- 일부 태블릿과 휴대폰은 받은 `.html` 파일을 바로 열지 못합니다. 그럴 때는 방법 2를 씁니다.
- 진행 상황은 학생 기기의 브라우저에 저장됩니다. 같은 기기, 같은 브라우저로 열어야 [이어하기]가 됩니다.

## 방법 2. 누리집 주소로 알려 주기

게임 파일을 누리집에 올리면 주소만 알려 주면 됩니다. QR 코드로 만들면 더 편합니다.

**학교나 교육청의 누리집, 클래스룸이 HTML 파일 올리기를 받아 주면** 그곳에 올립니다.

**GitHub Pages (무료):**

1. GitHub에 가입하고 새 저장소(Repository)를 만듭니다. 공개(Public)로 만듭니다.
2. 받은 게임 파일의 이름을 `index.html` 로 바꿔 [Add file → Upload files]로 올립니다.
3. 저장소 [Settings → Pages → Branch: main, / (root) → Save].
4. 1~2분 뒤 `https://(내 아이디).github.io/(저장소 이름)/` 로 열립니다.

키트 폴더를 통째로 저장소에 올리는 방법도 있습니다. `.github/workflows/pages.yml` 이 들어 있어서, [Settings → Pages → Source: GitHub Actions]만 고르면 `my-game/` 을 고칠 때마다 주소의 게임이 저절로 바뀝니다.

**알아 둘 것**

- 누리집에 올린 게임은 주소를 아는 누구나 볼 수 있습니다. 학생 이름, 학교 안의 사정이 드러나는 내용은 넣지 마세요.
- 게임 파일 안에는 정답이 들어 있습니다. 파일을 열어 볼 줄 아는 학생은 정답을 볼 수 있습니다. 점수를 매기는 평가보다는 **배움을 위한 활동**으로 쓰기를 권합니다.

## 수업 운영 요령

- **2인 1조**가 좋습니다. 한 명이 조작하고 한 명이 기록을 읽으면 "이게 모순 아니야?" 하는 대화가 생깁니다.
- 쓰기 활동은 **한 사람씩** 합니다. 게임을 끝내지 못한 학생은 처음 화면의 [○○만 하기] 버튼으로 쓰기 활동만 할 수 있습니다.
- 막힌 모둠에는 "기록을 다시 읽어 보자", "그 문장을 [더 묻기] 해 봤니?"라고 해 주세요. 같은 증언에서 두 번 틀리면 게임이 힌트를 줍니다.
- 끝난 뒤 5분은 꼭 남겨서 "처음에 누구를 의심했나요? 왜 생각이 바뀌었나요?"를 함께 이야기합니다. 이 게임의 배움은 그 대화에서 완성됩니다.
