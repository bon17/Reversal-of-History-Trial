# 완성 예시

## `memory-court-ep1/` 원작 「기억의 법정」 제1화 「군함도의 명부」

이 키트의 바탕이 된 중학교 역사 수업용 게임 「기억의 법정」(BONSSAM)의 제1화를 키트 형식으로 옮긴 것입니다.
**한 차시 분량의 완성된 게임이 어떻게 생겼는지** 보여 주는 예시입니다.

- 1944년 하시마(군함도) 탄광. 사고의 누명을 쓴 열일곱 살 광부 김석진을 변호합니다.
- 대사 약 230줄, 증거 16개, 증언 6개, 반격, 최종 변론, 실제 역사 기록 카드.
- 「누명을 벗긴다」 방식, 「기억·책임」 틀(🟥 피해 기록 / 🟦 책임 기록 / 🟩 선택 기록)을 씁니다.
- 인물, 배경, 증거 그림이 들어 있어서 **그림을 넣은 게임의 설정**(`settings.js`의 파일, 얼굴, 인물자리)도 볼 수 있습니다.

### 여는 법

키트 폴더의 **`example-memory-court.html`** 을 두 번 누릅니다.
(또는 `index.html` 주소 끝에 `?game=examples/memory-court-ep1` 을 붙입니다. 교사용으로 열려면 `&teacher` 를 더 붙입니다.)

### 이렇게 써 보세요

- **먼저 한 번 해 봅니다.** 피고가 의심받는 처음, 조사, 증언을 하나씩 깨는 흐름, 진범이 바뀌어 가는 구조를 봅니다.
- **`story1.js` 를 읽어 봅니다.** 증언 하나가 어떤 문장, 추궁, 정답, 힌트, 정답 장면으로 이루어지는지 볼 수 있습니다.
- **AI에게 예시로 줍니다.** "이 예시와 같은 짜임으로 내 단원의 이야기를 만들어 줘"라고 하면 됩니다.
- **고쳐서 내 수업에 씁니다.** 이 폴더를 통째로 복사해 `my-game` 으로 이름을 바꾸면 내 게임의 출발점이 됩니다.

### 원작과 다른 점

- 화면의 버튼, 대사창, 외침은 키트의 것으로 나옵니다 (원작의 화면 그림은 넣지 않았습니다).
- 교과서에 실린 하시마섬 사진은 넣지 않았습니다. 수업에서는 교과서를 함께 펴 주세요.
- 소리 파일은 없습니다. 1화만 들어 있어서 끝나면 끝 화면이 나옵니다.
