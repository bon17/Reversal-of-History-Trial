# 짧은 예시

역사판의 기본 예시(`my-game/`)는 원작 「기억의 법정」 제1화 「군함도의 명부」입니다. 키트의 `index.html` 을 열면 바로 나옵니다.
이 폴더에는 **그림 없이 만든 짧은 예시**가 있습니다.

## `daedong-map/` 「지도를 불태운 나라?」

"김정호는 옥에 갇히고 대동여지도 목판은 불태워졌다"는 널리 퍼진 이야기를 사료로 따져 보는 10분짜리 게임입니다.

- 「이야기를 재판한다」 방식: 지금의 학교 역사 동아리에서 모의재판을 엽니다. 실제 인물은 등장하지 않습니다.
- 「사료 비판」 틀: 🟦 당시의 자료 / 🟪 후대의 글 / 🟩 연구 결과. 사료마다 누가, 언제 남겼는지가 함께 보입니다.
- 그림이 하나도 없습니다. 이모지 인물과 색 배경만으로 어떻게 보이는지 알 수 있습니다.
- **만들기 도우미가 AI에게 주는 글에 형식 예시로 들어가는 게임이 이것입니다.** (짧아서 AI가 형식을 익히기 좋습니다)

### 여는 법

키트 폴더의 **`example-daedong-map.html`** 을 두 번 누릅니다.
(또는 `index.html` 주소 끝에 `?game=examples/daedong-map` 을 붙입니다.)

### 이 예시에서 시작하려면

이 폴더의 `settings.js`, `story1.js` 를 `my-game` 폴더에 덮어씁니다. 원작 예시의 그림(`my-game/images/`)은 지워도 됩니다.

### 확인할 것

이 예시의 사실(연도, 소장처, 신문과 교과서의 출처)은 `story1.js` 의 `사실확인` 목록에 적어 두었습니다. 수업에 쓰기 전에 원문으로 확인해 주세요.
