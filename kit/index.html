법정 추리 수업 게임 키트

내 수업 내용으로 법정 추리 웹 게임을 만듭니다. 코딩을 몰라도, 평소 쓰는 AI만 있으면 됩니다.

범용판

모든 교과

  • 학생들의 오개념을 교과 지식으로 뒤집는 게임
  • 예시: 「시든 화분 사건」 (과학, 약 10분)
예시 게임 해 보기 만들기 도우미 열기 안내 읽기

역사판

역사 수업

  • 통념과 왜곡된 주장을 사료로 뒤집는 게임
  • 예시: 원작 「기억의 법정」 제1화 「군함도의 명부」 (약 40분)
  • 짧은 예시: 「지도를 불태운 나라?」 (그림 없음, 약 10분)
예시 게임 해 보기 (군함도의 명부) 만들기 도우미 열기 짧은 예시 「지도를 불태운 나라?」 안내 읽기

만드는 순서

  1. 만들기 도우미에 수업 설계를 적습니다. (단원, 학습 목표, 핵심 지식이나 사료, 학생들의 오개념)
  2. 만들어진 글을 내 AI(Claude, ChatGPT, Gemini 등)에게 붙여 넣습니다.
  3. AI가 써 준 답을 붙여 넣고 점검합니다. 문제가 있으면 버튼 하나로 AI에게 다시 고쳐 달라고 합니다.
  4. 직접 해 보고 게임 파일 하나로 받아 학생에게 나눠 줍니다.
